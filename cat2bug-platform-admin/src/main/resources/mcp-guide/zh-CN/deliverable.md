## 交付物是什么

交付物是项目要交付的功能模块，组成一棵树（例如「登录 / 注册」「订单 / 支付」）。代码和接口里叫 `module`，工具参数是 `module_id`。缺陷、用例、计划子项都按交付物归类，统计和报告也按交付物汇总。

## 常用操作

| 目的 | 工具 |
|---|---|
| 查交付物树 | `list_modules`（可按名称过滤） |
| 新建 / 改名 / 删除 | 专用工具未提供，用 `list_operations(module=deliverable)` 找接口，再 `call_operation` |

## 使用建议

- 提缺陷、写用例前先 `list_modules`，按用户描述的功能找到最匹配的交付物；拿不准时把候选项列给用户选。
- 找不到合适的交付物：告诉用户，经确认后再新建；没有新建权限时请项目管理员或测试添加。
- 新建后汇报「已新建交付物『名称』（ID），可以开始在它下面写用例 / 提缺陷」。
