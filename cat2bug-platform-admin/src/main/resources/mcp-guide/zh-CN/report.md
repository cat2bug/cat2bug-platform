## 报告是什么

报告是项目里的 Markdown 文档，常用于测试报告、阶段总结。网页上可以按报告模板生成，并保留历史版本。

## 常用操作

| 目的 | 工具 |
|---|---|
| 查报告 | `list_reports` |
| 读正文 | `get_report`（正文过长会截断） |
| 新建 / 修改 | 专用工具未提供，用 `list_operations(module=report)` 找接口，再 `call_operation`（需要报告的新建 / 编辑权限） |

## 写测试报告的步骤

1. 收集数据：`get_project_stats`（缺陷按状态 / 类型统计）、`list_plans`（各计划通过率）、`search_defects`（未关闭的重要缺陷）。
2. 按用户要求拟出报告大纲与正文，先给用户看。
3. 用户确认后再写入平台，完成后汇报报告标题与 ID，建议用户到网页「报告」里查看排版。

只读汇总（不写入平台）时，直接把整理好的内容回复给用户即可。
