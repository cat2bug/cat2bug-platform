## 说明

本矩阵为 **摘要表**，用于展示关键岗位与能力项的达标情况；详细培训记录、考核证据见《培训记录》等成文信息。能力等级建议统一编码，例如：**0** 未要求 / **1** 了解 / **2** 独立执行 / **3** 指导他人 / **4** 专家。

（人工填写）组织适用的岗位列表与能力项定义见正文或附件《能力项字典》。
