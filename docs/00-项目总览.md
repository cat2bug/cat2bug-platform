# 项目总览：Cat2Bug-Platform（猫陪我改BUG）

开源的轻量级 AI 辅助 BUG 管理平台，面向软件团队管理缺陷、测试用例、测试计划、报告、文档和项目代码仓库。仓库 `https://github.com/cat2bug/cat2bug-platform`，当前版本 1.1.0，主开发分支 `core`。

## 技术栈

- 后端：Quarkus 3.15.7 + JDK 17（`cat2bug-platform-admin|framework|system|common`，包根 `com.cat2bug.*`，默认 `mvn package` 即产品构建），MyBatis，JGit。原 Spring Boot 线已删除，留档 tag `spring-final-1.1.0`。
- 前端：Vue 3.5 + Vite 6 + Element Plus + Pinia + Milkdown（`cat2bug-platform-ui`，开发端口 2222）。
- 数据库：MySQL / H2，Flyway 迁移；缓存 local 或 Redis。
- 部署：JVM 单 JAR（嵌入前端，端口 2020）、Docker Compose（仅 MySQL）、Native（UPX 后约 38.8 MiB）、rpm（Native ELF）。

详见 [[整体架构]]、[[数据库]]、[[部署]]。根目录 `CLAUDE.md` 不入库，与本库冲突时以本库为准。
