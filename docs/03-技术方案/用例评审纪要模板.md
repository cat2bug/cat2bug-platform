# 用例评审纪要模板

说明内置评审纪要 Markdown、占位符与团队种子行为。归属见 [[ADR-023-用例类型评审模板与缺陷属性归属团队]]；编辑器见 [[ADR-019-可视化Markdown统一用Tiptap连续A4纸面]]。

## 内置稿

- 资源路径：`case-review/default-template.md`（classpath）。
- 团队未配置或清空模板时，完成评审仍用该内置文件。

## 占位符

| 占位符 | 含义 |
|--|--|
| `{{project}}` | 项目名称 |
| `{{cases}}` | 用例明细表格 |

（其余占位符以实现为准。）

## 新建团队 / 项目

`SysTeamService` 创建团队后调用 `SysCaseTypeService.seedDefaultsForTeam`：预置「功能 / 接口 / 界面」，并在团队 `case_review_template` 为空时写入内置正文。新建项目改为 `ensureTeamDefaultsIfEmpty`（仅当所属团队尚无类型时补种）。团队设置页可再改模板；保存空字符串落库为 `null`，之后完成评审与 GET 回退到内置。

## API

- `GET/PUT /system/team/{teamId}/case-review-template`：管理读写（团队创建人/管理员）。
- `GET /system/project/{projectId}/case-review-template`：只读，经 project→team；库中为空时返回内置正文。
