# 主题与配色

说明前端浅色/暗色主题的切换机制、CSS 变量（token）体系与主色约定；写任何新样式前先查这里，避免写死颜色导致暗色主题不可读。

## 硬性规则

暗色对比度是硬性规则，以 `.cursor/rules/ui-dark-theme-contrast.mdc` 为准（作用于 `cat2bug-platform-ui/**/*.{vue,scss,css}`），要点：

- 颜色只用项目 token（见下文「变量体系」）：文字 `--text-color-primary|regular|secondary|placeholder`，背景 `--bg-color-*` / `--card-bg` / `--dialog-bg`，边框 `--border-color-*`，主色 `--cat2bug-primary`。禁止写死 `#333`、`#24292e`、`#303133`、`#fff` 等单一主题颜色。
- **项目没有引入 Element Plus 自带的暗色变量**，`--el-*` 只有在 `theme-dark.scss` 的 `html.dark` 中映射过才会随主题变化（目前含 `--el-text-color-*`、`--el-fill-color-blank|light`、`--el-border-color*`、`--el-bg-color-overlay`、`--el-color-primary`）。要用别的 `--el-*`，先在 `html.dark` 映射到项目 token。
- `<pre>`、`<code>`、只读文本块、气泡等自绘区域必须同时写字色和底色（推荐 `--text-color-primary` + `--bg-color-base` + 边框 `--border-color-light`），只改背景不改字色视为未完成。
- Markdown 渲染依赖全局 `html.dark .markdown-body` 覆盖；`h1`/`h2` 下划线用 `--divider-color` / `--border-color-light`，禁止 github 默认的 `#eaecef`（暗色下近纯白）。正文内标题尺度宜小于页面级标题（见 `index.scss` 对 `markdown-it-vue` 的覆盖）。
- 暗色 placeholder 用 `--text-color-placeholder`（`#8b8d94`），禁止接近底色的 `#4c4d4f`。
- `scoped` 样式覆盖子组件时，配合 `html.dark` 使用 `:deep(...)`。
- 自检：改完 UI 切到暗色看一遍，正文、辅助文字、代码块 / 配置示例、Markdown 预览、placeholder、弹窗内文字、自绘分栏 / 卡片底都要一眼可读，不能有大块浅色默认白底。踩坑见 [[暗色主题下el-text-color变量仍是浅色值导致文字看不清]]、[[暗色主题下臆造bg-color-overlay回退成大块白色]]、[[暗色主题下custom-class未生效导致统计卡仍是白底]]。
- Element Plus 的 Drawer / Dialog 用 `class` 挂类名。`custom-class` 不会进 `class`，写在该类名下的暗色覆盖不会生效。
- 禁止臆造不存在的项目 token（如 `--bg-color-overlay`）再 fallback 到未映射的 `--el-bg-color`：无效变量会落到 Element 浅色白底。

## 主题切换机制

- 主题模式 `light` / `dark` 存 `localStorage` 的 `theme-mode`，未设置时跟随系统 `prefers-color-scheme`。
- `applyThemeMode` 在 `<html>` 上增删 `dark` 类并设置 `color-scheme`；切换瞬间加 `theme-switching` 类禁用过渡、下一帧移除，避免闪烁。
- 侧栏主题 `sideTheme` 跟随主题模式同步（暗色 → `theme-dark`，浅色 → `theme-light`）。
- 代码：`cat2bug-platform-ui/src/utils/theme-mode.js`、`src/stores/settings.js`（Pinia `defineStore`）。

## 变量体系

所有主题 token 定义在 `cat2bug-platform-ui/src/assets/styles/theme-dark.scss`：`:root` 为浅色默认，`html.dark` 为暗色覆盖。按用途分组：

| 分组 | 代表变量 | 说明 |
|---|---|---|
| 背景 | `--bg-color-base`、`--bg-color-page`、`--bg-color-block` | 暗色下 page 与 base 同色，避免页面缝隙比卡片更深 |
| 文字 | `--text-color-primary/regular/secondary/placeholder`、`--form-label-color` | 硬性规则约束对象 |
| 边框/分割 | `--border-color-base/light/lighter`、`--divider-color` | |
| 容器 | `--card-bg`、`--dialog-bg`、`--drawer-bg`、`--dropdown-bg`、`--input-*` | 暗色统一 `#252529` 层 |
| 表格 | `--table-header-bg/color`、`--table-bg`、`--table-row-hover-bg`、`--table-border-color`、`--cat2bug-table-*` | |
| 侧栏/导航 | `--sidebar-*`、`--navbar-*`、`--tags-view-*`、`--team-select-*` | |
| 聚焦环 | `--cat2bug-field-focus-*` | 键盘焦点可见性，见 [[组件与交互约定]] |
| 业务标签 | `--defect-state-*`、`--defect-type-*`、`--star-switch-*`、`--member-overflow-badge-*` | 缺陷状态/类型等专用色 |
| 布局尺寸 | `--cat2bug-toolbar-*`、`--cat2bug-operate-tools-*`、`--cat2bug-dropdown-caret-inset` | 工具栏、操作列间距 |

全局尺寸类 token（对话框内边距、控件高度、圆角、页头等）在 `cat2bug-platform-ui/src/assets/styles/cat2bug.scss` 顶部 `:root`，例如 `--cat2bug-control-height`（32px）、`--cat2bug-border-radius`（4px）、`--cat2bug-dialog-padding-x`（20px）。

## 主色约定

- **品牌主色**：浅色与暗色共用 `#1890ff`（`--cat2bug-primary`，与 `element-plus-variables.scss` 的 Element Plus 编译主色一致）。success `#13ce66`、warning `#ffba00`、danger `#e64545` 不变。
- **页签 / 侧栏当前项 / 实心主按钮**：一律品牌主色 `#1890ff`（`--cat2bug-primary`）。页签图标跟文字同色（`currentColor` / `inherit`），不要单独刷白。
- **强调色 `--cat2bug-accent`**：浅色与主色同为 `#1890ff`；暗色为 `#69b1ff`，只用于文字链接与聚焦环（`--cat2bug-field-focus-color` 等），不要当页签激活色或按钮底。
- **琥珀黄退出品牌位**：`#FFC107` / `#ffce3a` 不再映射到 `--cat2bug-primary` 或 `--el-color-primary`；仅作警告语义或收藏星等业务色（星标金黄 `rgb(247,186,42)`）。
- 浅色按钮 hover 保持「白底 + 蓝字蓝边」，**禁止金色 hover**。
- 新组件引用主色一律用 `var(--cat2bug-primary)` / `var(--el-color-primary)`，不要写死 `#409eff`、`#1890ff` 或 `#FFC107`，否则另一主题或后续换色会错。CSS 回退色与侧栏 `--sidebar-item-active-bg` 兜底也用蓝（`#1890ff` / 暗色半透明），不要再用琥珀。
- 验证码插画太阳/花芯、Markdown 引用块左边线、项目预设图标里的琥珀块属于图形语义，可保留黄，不要刷成品牌蓝。

## 样式文件组织

- 入口 `cat2bug-platform-ui/src/assets/styles/index.scss` 依次引入 `variables.scss`、`element-ui.scss`、`sidebar.scss`、`btn.scss`、`theme-dark.scss`、表格/分栏相关样式等。
- `variables.scss`：Sass 变量（旧侧栏配色、`$base-sidebar-width: 200px` 等），并通过 `variables.js` 导出给 JS。
- `element-plus-variables.scss`：Element Plus 主题色与组件尺寸（default/small 都是 32px，对齐旧版 Element UI small）。
- 设置页左侧分组导航规范：`readme/development/ui/settings-sidebar.md`。
