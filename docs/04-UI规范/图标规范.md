# 图标规范

说明前端三类图标（自有 SVG 雪碧图、Element Plus 图标、少量 PNG）的来源与用法，以及菜单图标 `sys_menu.icon` 与 SVG 文件名的对应关系；新增菜单或图标时参考，避免菜单图标空白。

## 自有 SVG 图标（SvgIcon）

- **目录**：`cat2bug-platform-ui/src/assets/icons/svg/`（当前 215 个），**文件名（不含 `.svg`）就是图标名**。
- **注册**：`vite-plugin-svg-icons` 在构建时把该目录打成雪碧图，`symbolId` 规则为 `icon-[name]`；入口 `src/assets/icons/index.js` 引入 `virtual:svg-icons-register`（配置见 `cat2bug-platform-ui/vite.config.js` 的 `createSvgIconsPlugin`）。
- **使用**：`<svg-icon icon-class="bug" />`（`src/components/SvgIcon/index.vue`），渲染为 `<use href="#icon-bug">`；`icon-class` 是外链 URL 时改用 CSS mask 显示。
- **着色**：`.svg-icon` 设置 `fill: currentColor`、尺寸 `1em`，即图标跟随文字颜色与字号，自动适配浅色/暗色主题（见 [[主题与配色]]）。新增 SVG 应去掉写死的 `fill` 颜色；当前有 21 个文件写死了颜色（文件类型图标 `pdf`、`docx`、`xlsx` 等，语言旗帜 `lang_*`，`validCode`、`download`、`dir`、`unknown-file`），这类是有意保留原色的彩色图标。

## 菜单图标与 `sys_menu.icon`

- 菜单表 `sys_menu.icon` 存的是 SVG **文件名**；后端 `getRouters` 返回的路由 `meta.icon` 由侧栏 `src/layout/components/Sidebar/Item.vue` 直接交给 `SvgIcon` 渲染。
- 图标值为空或 `#` 时不渲染图标。
- **对应文件不存在时不会报错，只会显示空白**（`<use>` 指向不存在的 symbol）——新增菜单（包括写在 Flyway 迁移脚本里的菜单）必须同时把同名 SVG 放进 `src/assets/icons/svg/`。
- 前端可按路由 path 覆盖图标：`src/utils/menu-icon.js` 的 `MENU_ICON_OVERRIDES`（目前 `team-options` / `team-option` → `team-option`），在 `src/stores/permission.js` 生成路由时调用。
- 菜单管理页（`src/views/system/menu/index.vue`）的图标选择器 `src/components/IconSelect/` 通过 `import.meta.glob` 列出同一目录下的全部 SVG，所以放进目录即可被选到。
- 核对方法：把 `cat2bug-platform-admin/src/main/resources/db/migration/` 中 `sys_menu` 的 `icon` 取值与 SVG 文件名比对。按此方法粗查，迁移脚本中出现的 34 个图标值均有对应文件（脚本解析为简易正则，结果仅供参考；线上库中手工改过的菜单不在此范围）。

## Element Plus 图标

- 依赖 `@element-plus/icons-vue`，组件内直接按需使用。
- 旧 Element UI 的字符串图标（`el-icon-xxx`）通过全局 `$legacyIcon('el-icon-xxx')` 转成 Element Plus 图标组件：能按「kebab → Pascal」自动推断的直接转换，推断不了的在 `src/utils/element-icon.js` 的 `LEGACY_ICON_MAP` 里登记（如 `el-icon-s-home` → `HomeFilled`）。模板中还有 `src/components/LegacyIcon/` 组件可用。
- 新代码优先直接用 Element Plus 图标组件；`$legacyIcon` 用于迁移期存量代码和以字符串保存在数据里的图标。

## PNG 与其它

- Git 模块少量位图在 `src/assets/icons/git/`（`open-source.png`、`release.png`、`tag-o.png`）；项目封面等较大 SVG 经 svgo 压缩过（见 `openspec/changes/archive/2026-10-14-restore-quarkus-full-delivery/NATIVE-RELEASE.md` 的前端瘦身记录）。
- 新增位图前先压缩（pngquant / oxipng），控制嵌入包体积。
