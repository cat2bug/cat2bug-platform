# 组件与交互约定

汇总前端通用组件（表格、分页、对话框/抽屉、确认框与提示）和键盘交互的约定；新写列表页、弹框或快捷键前先看这里，保持全站一致。颜色相关见 [[主题与配色]]，图标见 [[图标规范]]。

## 技术基线

- Vue 3.5 + Vite 6 + Element Plus 2.9 + Pinia 2 + vue-router 4；Element Plus 是**唯一**组件库，旧 Element UI 字符串图标通过 `$legacyIcon` 兼容（见 [[图标规范]]）。
- **控件轨**：高度全站 32px（`--cat2bug-control-height`），Element Plus 的 `default` 与 `small` 尺寸都被设成 32px，以对齐旧版 Element UI small；表单、抽屉、对话框、`el-message-box` 统一套用这一高度。列表工具栏上不必再写 `size="small"`（高度已被强制）。
- **表格轨**：单行最小约 **56px**（`--cat2bug-table-row-min-height`），cell 上下留白 `--cat2bug-table-cell-padding-y`（默认 **16px**）；相对 Element Plus default（约 8px / ~39px）应肉眼可感更松。数据行最高仍 100px（`--cat2bug-table-row-max-height`）。全局业务 `el-table` 与 `Cat2BugTable` 共用此轨。
- 圆角 `--cat2bug-border-radius: 4px`；按钮图标与文字间距 `--cat2bug-button-icon-text-gap: 5px`；工具栏控件间距 `--cat2bug-toolbar-item-gap: 10px`。

## 列表页工具条

列表上方单独一行，参考缺陷列表（`defect-page` 的 `.defect-view-toolbar`）。新列表页用 `.list-page-toolbar`（`cat2bug-platform-ui/src/assets/styles/project-list-page.scss`）。

- **左** `.list-page-toolbar__filters`：查询过滤。下拉、输入框左侧都带图标（`prefix` / `prefix-icon`）。改值即查（`@input` / `@change`），不放「查询」按钮。没有筛选项时留空槽，不要把操作按钮放到左边。**程序化 hydrate**（恢复本地偏好、应用服务端 tab/筛选配置等）改写 `queryParams` 期间，须抑制表单 `@change`/`@input` 旁路拉列表，改完后由统一入口只请求一次（参考缺陷页 `_suppressDefectQueryFetch` / 变更 `defect-tab-single-list-on-restore`）。
- **右** `.list-page-toolbar__actions`：工具按钮，一般是图标 + 文字（如「添加类型」）。**主新建/添加**用 `type="primary" plain`，并加 `cat2bug-btn-outline`（或依赖 `.list-page-toolbar` / `module-tools` / `project-option-list-tools` 作用域兜底），与筛选同高、同为描边/轻底重量。不要只写 `plain`：浅色全局会把无 outline 的 primary plain 画成实心蓝，暗色同理。
- **间距**：这一行与上一行、与下方列表都是 10px，用 `--project-list-section-v-gap`（别写死另一个数）。行内左右区间距 `--cat2bug-toolbar-section-gap`，换行行距 `--cat2bug-toolbar-row-gap`。
- **窄屏**：父级 `flex-wrap`，左侧优先占宽，右侧工具条放不下时整组换到下一行（与缺陷列表相同）。按钮高度仍是 32px（`--cat2bug-control-height`）。

## 表格：Cat2BugTable

所有业务列表（缺陷、用例、计划、文档、交付物、OpenAI 账号及计划抽屉内嵌列表等）统一用 `cat2bug-platform-ui/src/components/Cat2BugTable/index.vue`，不要直接裸用 `el-table`。树表可透传 `row-key` / `tree-props` / `default-expand-all` / `highlight-current-row`。

- **表头手柄**：hover 表头时出现两个控件，未 hover 时不可见且不可交互。顺序固定为「拖序手柄（六点）→ pin 图标 → 列标题 → 排序箭头 → 调宽竖条（叠在右缘）」。操作列、prepend 辅助列、`pinFixedToggle === false` 的列不显示手柄。树节点展开点在首列内容区，与表头手柄不冲突。
- **拖序**：只能从拖序手柄发起（Sortable 的 `handle` 限定），不得与 pin 点击、排序点击冲突。
- **pin**：点击切换左固定；左固定列复制的表头里手柄行为要与主表一致，调宽/拖序后必须 `doLayout` 并同步固定列行高、自定义横向滚动条。
- **列宽**：最小 60px；用户调整的宽度与 `visible`、`fixed`、列顺序一起写入同一份本地缓存（防抖写入，key 由 `cacheKey` 区分）；无用户宽度时依次回退列定义的 `width_<locale>`、`width`、组件默认值。
- **行高**：遵循表格轨最小约 56px（`--cat2bug-table-row-min-height`）、cell 上下 `--cat2bug-table-cell-padding-y`（16px）；数据行最高 100px。全局 CSS **必须覆盖** ConfigProvider `size=small` 产生的 `.el-table--small` 默认紧凑 padding，否则裸 `el-table` 会矮一截。刻意紧凑的嵌套/说明表加 `cat2bug-table-compact`。普通文本列在行高内最多 4 行，放不下以省略号结尾。缺陷名称标题最多 3 行（下面还有统计行）。操作列、图片、状态标记不改成文本截断；用例步骤列在行高内自行滚动。坑：[[EP-small表压过表格轨token]]。
- **操作列**：默认自动宽度（`operateColumnAutoWidth`），范围 88~450px；未测出内容前 `--cat2bug-operate-col-applied-width` 占位为下限（88），测完再写入。测宽 MUST 用内容固有宽（克隆 / 子节点累加），**禁止**用已被列宽撑开的 `scrollWidth` / `getBoundingClientRect` 回灌，否则会卡在 450。超上限才 `data-operate-at-cap` 换行。行内按钮间距 `--cat2bug-operate-tools-gap`（10px）；操作图标统一 `--cat2bug-operate-icon-size`（14px，含缺陷操作列、收藏星、源码列表纯图标钮）。text/link 按钮用 `--cat2bug-operate-text-*` 语义色，在单元格内垂直居中。历史 class `small-padding` 只表示操作列窄布局，**不是** Element Plus 的 `size="small"`。坑：[[操作列自动宽live-rect反馈放大卡在450]]。
- **操作列 CRUD 色**（对齐缺陷列表）：**修改** `class="green"` → `--cat2bug-operate-text-success`；**添加**（行内新增子项等）`class="blue"` → `--cat2bug-operate-text-primary`；**删除** `class="red"` → `--cat2bug-operate-text-danger`。色值只走 token，业务页不写死十六进制。缺陷流转钮继续用 `orange` / `restore-orange`，不要改成绿/蓝。无语义的查看/测试/下载等可不打 class（默认品牌蓝）。
- **排序**：列默认服务端排序（`sortable="custom"`），自定义字段列不可排序；排序参数与后端约定见 `docs/03-技术方案/` 的 [[列表排序与注入防护]]。
- **暗色**：手柄颜色用 `--cat2bug-col-handle-grip-color(-active)` 等 token，保证暗色下可见。

## 空状态：Cat2BugEmpty

列表、抽屉、对话框里「暂无数据」统一用 `cat2bug-platform-ui/src/components/Cat2BugEmpty/index.vue`（已全局注册为 `Cat2BugEmpty` / `cat2-bug-empty`），不要裸用 `el-empty` 或旧占位图。

- **文案**：`description` 字符串，或 `#description` 插槽；默认插槽可放操作按钮。
- **尺寸**：`size` 取 `small` / `default` / `large`，同时控制插画边长与说明字号（约 80/120/260 px 与 12/14/14 px）。源码仓库整页空态用 `large`。需要精确边长时可用 `imageSize` 数字覆盖插画，字号仍跟 `size`。
- **动效**：箱子缓慢上下浮；上移时地影略小略淡，下移时略大略实。`prefers-reduced-motion: reduce` 时关闭动画。
- **插画**：空纸箱 + 简笔猫头，资源 `src/assets/images/cat2bug-empty-box.png`；暗色用亮度压暗贴近页面底，不做羽化压糊。

## 错误整页：ErrorStateShell

404 / 401 / 团队禁用 / 项目禁用等**主内容区错误态**用 `cat2bug-platform-ui/src/components/ErrorStateShell/index.vue`，**不要**套 `Cat2BugEmpty`（错误页需要大状态码与多操作，且不做空箱子浮动）。

- **壳**：路由挂在 `Layout` 下（与 team-lock / project-lock 一致），保留左侧菜单与顶栏；壳只铺满 `app-main`，不另开全屏孤页。
- **结构**：插画 → 大状态码（数字或 TEAM/PROJECT）→ 标题 → 说明 → 操作区（`#actions`）。
- **插画**：狸花猫定稿图，`src/assets/images/error/{404,401,disabled}-{light,dark}.png`；按 `html.dark` / `themeMode` 切换浅/深，不用滤镜压暗。
- **禁用页**：团队禁用与项目禁用共用 `disabled` 插画，文案与业务操作各自保留。

## 分页

- 用 `src/components/Pagination/index.vue`：默认 `page=1`、`limit=10`、可选每页 `10/20/30/50`、布局 `total, sizes, prev, pager, next, jumper`，窄屏（<992px）页码按钮减为 5 个。
- 后端分页协议见 [[分页与统一响应]]。
- **文档列表**每页条数写入全局本地键 `document.pageSize`；进入页须先读该值再发起首次 `list`，避免默认 10 查完再换成缓存值二次请求。

## 文档页左侧文件夹树

文档管理（`views/system/document/index.vue`）左侧为文件夹树，交互壳对齐缺陷交付物树（`vue-multipane` + 显隐），组件为 `components/Document/DocumentFolderTree.vue`，**不要**复用交付物 `TreeModule` 业务数据。

- **显隐**：全局本地键 `document_folder_tree_visible`（`1`/`0`）；树宽可 session 缓存 `document_folder_tree_width`。
- **导航**：树节点 / 列表文件夹行 / 「上级目录」行共用 `applyFolder`，互相同步高亮；右侧列表仍显示子文件夹与文件。
- **搜索**：树顶模糊匹配**全项目**文件夹名（不传 `docPid` 拉 `docType=0` 后本地建树过滤）。
- **批处理**：多选后工具条在「新建文件夹」前提供批量移动、批量删除；删前确认，文件夹级联由后端保证。

## 对话框、抽屉与键盘关闭

- 对话框/抽屉内边距、内容与底栏间距用 `--cat2bug-dialog-padding-x`（20px）、`--cat2bug-dialog-content-footer-gap`（20px）、`--cat2bug-dialog-footer-gap`（10px）。
- 对话框内表单的描述、附件、图片上传等控件满宽。
- **表单回车**：`el-form` 须 `@submit.prevent`（可接到业务提交）；页脚按钮宜 `native-type="button"`。单输入框对话框若漏 prevent，回车会走原生 submit 像整页刷新。坑：[[对话框单输入框回车触发表单原生submit整页刷新]]。
- 键盘：`Esc` 关闭最上层表单浮层，`⌘/Ctrl + Enter` 保存（`isEscapeCloseKey` / `isSaveShortcutKey`，输入法组字时不触发）；对话框表单通过 `useDialogFormShortcuts` 接入，组件可定义 `$_formShortcutSurfaceVisible` 自定义「浮层是否可见」。存在阻塞性浮层（下拉、日期面板、图标弹层等）时先关浮层，不直接关对话框。
- 各模块专用的关闭/快捷键逻辑在 `src/composables/keyboard/use*DialogClose.js`、`use*DrawerClose.js`、`use*Kbd.js`。

## 文本中的缺陷编号

- PR 详情标题与描述（以及后续同类文本）中，形如 `#61` 的项目内缺陷编号可点击；点击后从**右侧抽屉**打开该缺陷（复用 `HandleDefect`），不离开当前页。
- 解析范围：非代码围栏（fenced code）正文；围栏内的 `#数字` 保持纯文本。
- 查不到缺陷或无权限时用 `$modal.msgWarning`，不打开空抽屉。

## 确认框与提示

- 统一走 `$modal`（`src/plugins/modal.js`）：
  - 轻提示 `msg` / `msgSuccess` / `msgError` / `msgWarning`，底层是 `src/utils/app-message.js`（顶部居中、可关闭、3 秒、合并同类提示）；**不要直接调 `ElNotification` 做普通提示**。
  - 弹窗 `alert*`、确认 `confirm`（默认 `warning` 类型，按钮文案走 i18n）、输入 `prompt`、全屏 `loading` / `closeLoading`。
- 删除等破坏性操作必须先 `$modal.confirm` 再调接口。

## 键盘可访问性

- **适配层**：业务键盘逻辑不得直接写 Element Plus 的 DOM 选择器或调用其内部 API，统一经 `src/adapters/element-plus/`（`table`、`select`、`dropdown`、`popover`、`date-picker` 适配器）访问，升级 Element Plus 时只改适配层。
- **组合式**：旧的键盘 mixin 已迁为 `src/composables/keyboard/use*.js`，新代码用 composable，不再写 mixin。
- **快捷键保留字**：`src/plugins/shortcut/reserved-keys.js` 统一维护。页面动作保留单字母 `A C M N Q T V X Z`；表单字段提示与键盘设置页额外禁止 `W R L H`（浏览器/系统窗口相关）；`⌘/Ctrl + [` `]` 留给浏览器前进后退。新增快捷键先查这里避免冲突。
- **回归**：键盘行为由 Playwright e2e 守护（`cat2bug-platform-ui/e2e/`），改键盘逻辑后需跑相关用例。

## 可视化 Markdown：Cat2BugEditor

通用可视化 Markdown 编辑器用 `cat2bug-platform-ui/src/components/Cat2BugEditor/index.vue`（Tiptap）。选型与边界见 [[ADR-019-可视化Markdown统一用Tiptap连续A4纸面]]。

- **存盘**：`v-model` 是 Markdown 字符串；有尺寸的图片写成带 `width`/`height` 的块级 HTML，普通图仍用 `![](url)`。
- **顶栏**：复用 `MarkdownTools` + `ToolsMenu`；默认只有排版工具。业务插入项用 `includeBusinessTools`。需要业务页保存时用 `show-save`，经 `@save` 回调；勿在编辑器下方再放独立保存行。
- **纸面（默认）**：`paper` 默认 `true`。内容区按 A4 宽 210mm、页边距上/下约 25mm、左/右约 20mm，浅底上的纸居中，正文连续加长、**不分页断页**。打印用同规格 `@page`（行宽对齐，页间断点不保证与屏幕一致）。
- **扁平壳 `flat`**：与 `paper` 同开时去掉内容区内层边框/阴影与多余上下间隔，纸面与左右托盘同色（`--bg-color-base`，全页编辑场景）。未保存离开（返回 / 路由跳转 / 关页）须确认。
- **窄场景**：弹框等用 `:paper="false"`，编辑区铺满容器。
- **图片**：可选中后四角拖拽缩放；剪贴板粘贴图片走 `/common/upload`，与工具条「上传图片」同一路径。
- **颜色**：纸面与托盘用项目 token（如 `--bg-color-base` / `--bg-color-block`），暗色下仍可读，不写死白/灰。

当前接入：文档 Markdown 编辑页与项目「评审纪要模板」页（均为 `paper` + `flat` + 工具条保存）；用例「完成评审」后的纪要正文（弹框内 `paper=false`）。缺陷描述等源码编辑仍可用 `Cat2BugMarkdown`，迁入另开变更。
