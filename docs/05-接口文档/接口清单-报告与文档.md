# 接口清单：文档

项目文档与 Markdown 初始化数据的 Quarkus 接口速查；约定见 [[接口约定]]。

> 原「报告」接口（`/system/report`、`/system/report/template`、`POST /api/report/defect`）已随 [[ADR-018-移除报告模块且不保留历史数据]] 删除。

资源类目录：`cat2bug-platform-admin/src/main/java/com/cat2bug/admin/resource/`。`—` 表示仅需登录或免登录。

## Markdown

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET | `/markdown/{projectId}` | Markdown 编辑器初始化数据（`MarkdownResource`） | `system:defect:list` / `system:case:list` / `system:plan:list` / `system:document:list` 任一 |

## 文档 `DocumentResource`（`/system/document`）

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET | `/system/document/list` | 项目文档分页 | `system:document:list` |
| GET | `/system/document/{docId}` | 详情 | `system:document:query` |
| POST/PUT | `/system/document` | 新建 / 编辑 | `system:document:add` / `:edit` |
| DELETE | `/system/document/{docIds}` | 删除 | 方法上无 `@RequiresPermissions`（仅需登录，是否在服务层校验「待确认」） |
| POST | `/system/document/export` | 导出 | `system:document:export` |

- 文档正文与编辑历史存于每项目一个的隐藏 Git 文档仓（slug `cat2bug-docs`），Quarkus 端 `DocumentResource` 只暴露上述 CRUD；文档历史/版本查看接口在 Quarkus 中未找到 `@Path`，是否尚未迁移「待确认」。
- 缺陷评论接口 `/system/comment/**` 见 [[接口清单-缺陷与用例计划]]；仪表盘文档统计同见该篇。
