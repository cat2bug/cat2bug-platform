# 接口清单：报告与文档

测试报告、报告模板（含预制模板）、Markdown 初始化数据与项目文档的 Quarkus 接口速查；约定见 [[接口约定]]。

资源类目录：`cat2bug-platform-admin/src/main/java/com/cat2bug/admin/resource/`。`—` 表示仅需登录或免登录。

## 报告 `ReportResource`（`/system/report`）

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET | `/system/report/list` | 报告分页 | `system:report:list` |
| GET | `/system/report/{reportId}` | 详情 | `system:report:query` |
| POST/PUT | `/system/report` | 新建 / 编辑 | `system:report:add` / `:edit` |
| DELETE | `/system/report/{reportIds}` | 删除 | `system:report:remove` |
| POST | `/system/report/export` | 导出 | `system:report:export` |
| GET | `/system/report/{reportId}/history` | 历史版本列表 | `system:report:query` |
| GET | `/system/report/history/{historyId}` | 历史版本详情 | `system:report:query` |
| POST | `/system/report/history/{historyId}/restore` | 恢复到历史版本 | `system:report:edit` |
| DELETE | `/system/report/history/{historyId}` | 删除历史版本 | `system:report:edit` |
| POST | `/system/report/close-edit-window` | 释放编辑占用 | — |

## 报告模板 `ReportTemplateResource`（`/system/report/template`）

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET | `/system/report/template/list` · `/picker` | 模板分页 / 选择器数据 | `system:report:list` |
| GET | `/system/report/template/{templateId}` | 详情 | `system:report:list` |
| POST/PUT | `/system/report/template` | 新建 / 编辑 | `system:report:add` |
| DELETE | `/system/report/template/{templateIds}` | 删除 | `system:report:add` |
| POST | `/system/report/template/export` | 导出 | `system:report:export` |
| GET | `/system/report/template/preset/{group}[/{folder}]/{key}/content` | 预制模板内容 | `system:report:list` |
| GET | `/system/report/template/preset/{group}[/{folder}]/{key}/preview` | 预制模板预览图（供 `<img>` 加载） | 免登录 |
| POST | `/system/report/template/preset/{group}[/{folder}]/{key}/copy` | 复制预制模板为项目模板 | `system:report:add` |

预制模板资源在 `cat2bug-platform-admin/src/main/resources/报告/`（目录结构与 group/folder/key 的对应关系「待确认」）。

## Markdown 与文档

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET | `/markdown/{projectId}` | 报告编辑器初始化数据（`MarkdownResource`） | `system:report:list` |
| GET | `/system/document/list` | 项目文档分页（`DocumentResource`） | `system:document:list` |
| GET | `/system/document/{docId}` | 详情 | `system:document:query` |
| POST/PUT | `/system/document` | 新建 / 编辑 | `system:document:add` / `:edit` |
| DELETE | `/system/document/{docIds}` | 删除 | 方法上无 `@RequiresPermissions`（仅需登录，是否在服务层校验「待确认」） |
| POST | `/system/document/export` | 导出 | `system:document:export` |

- 文档正文与编辑历史存于每项目一个的隐藏 Git 文档仓（slug `cat2bug-docs`），Quarkus 端 `DocumentResource` 只暴露上述 CRUD；文档历史/版本查看接口在 Quarkus 中未找到 `@Path`，是否尚未迁移「待确认」。
- 报告/缺陷评论接口 `/system/comment/**` 见 [[接口清单-缺陷与用例计划]]；仪表盘报告/文档统计同见该篇。
