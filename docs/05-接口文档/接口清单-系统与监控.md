# 接口清单：系统与监控

登录注册、用户/角色/菜单/部门/岗位/字典/参数、通知公告、日志、在线用户、服务器、缓存、定时任务，以及安装/升级向导的 Quarkus 接口速查；约定见 [[接口约定]]。

资源类目录：`cat2bug-platform-admin/src/main/java/com/cat2bug/admin/resource/`。`A|B` 表示任一权限即可，`—` 表示仅需登录或免登录。

## 日志与监控

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET | `/monitor/operlog/list` | 操作日志（`OperlogResource`）；`operChannel` 按渠道筛选（`web` 匹配 NULL、`mcp`） | `monitor:operlog:list` |
| DELETE | `/monitor/operlog/{operIds}`、`/clean` | 删除 / 清空 | `monitor:operlog:remove` |
| GET | `/monitor/logininfor/list` | 登录日志（`LogininforResource`） | `monitor:logininfor:list` |
| DELETE | `/monitor/logininfor/{infoIds}`、`/clean` | 删除 / 清空 | `monitor:logininfor:remove` |
| GET | `/monitor/logininfor/unlock/{userName}` | 解锁账号 | `monitor:logininfor:unlock` |
| GET | `/monitor/online/list` | 在线用户（`MonitorResource`） | `monitor:online:list` |
| DELETE | `/monitor/online/{tokenId}` | 强制下线 | `monitor:online:forceLogout` |
| GET | `/monitor/server` | 服务器信息 | `monitor:server:list` |
| GET | `/monitor/cache`、`/getNames`、`/getKeys/{cacheName}`、`/getValue/{cacheName}/{cacheKey}` | 缓存概览与浏览 | `monitor:cache:list` |
| DELETE | `/monitor/cache/clearCacheName/{cacheName}`、`/clearCacheKey/{cacheKey}`、`/clearCacheAll` | 清理缓存 | `monitor:cache:list` |
| GET | `/druid`、`/druid/{page}` | Druid 连接池监控页（`DruidMonitorResource`，按 Cookie 自鉴权） | 免 JWT |

各日志的 `POST .../export` 同时提供表单与 JSON 两种入参版本（`exportForm` / `exportJson`），权限为对应 `:export`。

| 方法 | 路径 | 说明 |
|---|---|---|
