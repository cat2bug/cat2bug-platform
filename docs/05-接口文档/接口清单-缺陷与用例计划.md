# 接口清单：缺陷与用例计划

缺陷、缺陷字段/标签/日志/评论/统计、模块、测试用例、测试计划相关的 Quarkus 接口速查；约定见 [[接口约定]]。

资源类目录：`cat2bug-platform-admin/src/main/java/com/cat2bug/admin/resource/`。权限列中 `A|B` 表示任一即可（`logical = OR`），`—` 表示仅需登录或免登录。

## 缺陷 `DefectResource`（`/system/defect`）

指派 / 修复 / 驳回 / 通过 / 关闭 / 重新打开在后端校验当前状态（`SysDefectService.requireTransition`），非法流转返回 HTTP 409；已删除的缺陷同样 409。

类型与状态（与 Spring 线一致，见 `SysDefect`、`DefectEnumJson`）：

- 输出：`defectType` 为名字（`BUG` / `TASK` / `DEMAND`），`defectState` 为数字 0～4；另有只读的 `defectTypeName`、`defectStateName`（名字），前端按名字字段显示与判断可执行的操作。
- 输入：请求体与查询参数里的 `defectType`、`defectState` 名字（不区分大小写）或数字都接受，非法值返回 400；回传的 `defectTypeName`、`defectStateName` 被忽略。
