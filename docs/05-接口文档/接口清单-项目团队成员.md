# 接口清单：项目、团队与成员

项目、团队、成员、邀请链接、平台管理员锁定及项目级 IM 通知配置的 Quarkus 接口速查；约定见 [[接口约定]]。

资源类目录：`cat2bug-platform-admin/src/main/java/com/cat2bug/admin/resource/`。`A|B` 表示任一权限即可，`—` 表示仅需登录或免登录。

## 项目 `ProjectResource`（`/system/project`）

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET | `/system/project/list` | 项目分页 | `system:project:list` |
| GET | `/system/project/{projectId}` | 详情（`projectId` 限数字） | `system:project:query` |
| GET | `/system/project/path/{teamKey}/{projectKey}` | 按团队/项目 key 解析项目 | `system:project:query` |
| POST/PUT | `/system/project` | 新建 / 编辑 | `system:project:add` / `:edit` |
| DELETE | `/system/project/{projectId}` | 删除 | `system:project:remove` |
| POST | `/system/project/export` | 导出 | `system:project:export` |
| GET | `/system/project/{projectId}/role` | 项目角色 | `system:project:list` |
| GET | `/system/project/{projectId}/member` | 项目成员 | `system:project:list\|system:project:member` |
| GET | `/system/project/{projectId}/not-member` | 非成员候选（全局已注册用户，排除已在项目中者；`params[search]` 按昵称/手机/邮箱模糊匹配，空关键词不返回全库；行含 `teamMember` 是否本团队成员） | `system:project:member:add` |
| POST | `/system/project/{projectId}/member` | 添加成员（body: `memberIds` + `roleIds`；写入项目成员与角色，不写入团队） | `system:project:member:add` |
| PUT | `/system/project/{projectId}/member/{memberId}/role` | 修改成员角色 | `system:project:member:update` |
| DELETE | `/system/project/{projectId}/member/{memberId}` | 移除成员 | `system:project:member:remove` |
| GET / PUT | `/system/project/{projectId}/mcp` | 项目 MCP 设置（开关、开放模块；`ProjectMcpResource`），按目标项目角色再校验，见 [[MCP接入与权限]] | `system:project:query` / `system:project:edit` |
| POST | `/system/project/{projectId}/invite-link` | 创建邀请链接 | `system:project:member:add` |
| GET | `/system/project/{projectId}/invite-links` | 邀请链接列表 | `system:project:member:add` |
| DELETE | `/system/project/{projectId}/invite-link/{inviteId}` | 撤销邀请链接 | `system:project:member:add` |
| POST | `/system/project/{projectId}/push` | 项目推送 | `system:project:push` |
| POST | `/system/project/{projectId}/collect` | 收藏项目 | `system:project:list` |
| GET/POST/PUT/DELETE | `/system/statistic`（`/list`、`/{id}`、`/{ids}`、`/export`） | 项目统计模板（`StatisticTemplateResource`） | 多为 `system:project:list`，详情 `system:project:query`，导出 `system:statistic:export` |

## 团队 `TeamResource`（`/system/team`）

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET | `/system/team/list` | 团队分页 | `system:team:list` |
| GET | `/system/team/my` | 我的团队 | — |
| GET | `/system/team/{teamId}` | 详情 | `system:team:query` |
| GET | `/system/team/{teamId}/role` | 团队角色 | `system:team:query` |
| GET | `/system/team/{teamId}/member`、`/{teamId}/not-member` | 成员 / 非成员 | — |
| POST/PUT | `/system/team` | 新建 / 编辑 | `system:team:add` / `:edit` |
| DELETE | `/system/team/{teamIds}` | 删除 | `system:team:remove` |
| POST | `/system/team/export` | 导出 | `system:team:export` |
| POST | `/system/team/{teamId}/member` | 直接创建成员账号 | `system:team:member:create` |
| POST | `/system/team/{teamId}/invite` | 邀请已有用户 | `system:team:member:invite` |
| POST/GET/DELETE | `/system/team/{teamId}/invite-link`、`/invite-links`、`/invite-link/{inviteId}` | 团队邀请链接 | `system:team:member:invite` |
| PUT | `/system/team/{teamId}/member/{memberId}/role`、`/roles` | 修改成员角色（单个 / 多个 roleIds） | `system:team:edit` |
| PUT | `/system/team/{teamId}/lock` | 锁定团队 | `system:team:lock` |

## 邀请落地 `InviteResource`（`/invite`）

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET | `/invite/{token}/preview` | 邀请预览 | 免登录 |
| GET | `/invite/{token}` | 旧版直链打开邀请页 | 免登录 |
| POST | `/invite/{token}/accept` | 接受邀请 | 需登录 |

## 成员与平台管理

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| POST | `/system/member/export` | 成员导出（`MemberResource`） | `system:user:export\|system:member:export` |
| POST | `/system/member/importTemplate` | 成员导入模板 | — |
| GET | `/admin/project/list` | 平台管理员查看全部项目（`AdminProjectResource`） | `admin:project:list` |
| PUT | `/admin/project/{projectId}/lock` | 锁定项目 | `admin:project:lock` |
| GET | `/admin/team/list` | 平台管理员查看全部团队（`AdminTeamResource`） | `admin:team:list` |
| PUT | `/admin/team/{teamId}/lock` | 锁定团队 | `admin:team:lock` |

成员的增删改查实际走用户接口 `/system/user/**`（见 [[接口清单-系统与监控]]）；Quarkus 的 `MemberResource` 只有上述两个接口，其余成员能力是否已全部并入团队/项目接口「待确认」。

## 项目 IM 通知配置

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET/POST | `/im/project/ding/config` | 钉钉配置读取 / 保存（`DingConfigResource`） | `ding:query` / `ding:save` |
| POST | `/im/project/ding/config/group-test`、`/single-test` | 钉钉群/单聊测试 | `ding:query` |
| GET/POST | `/im/project/feishu/config`（含 `/group-test`、`/single-test`） | 飞书配置与测试（`FeishuConfigResource`） | `feishu:query` / `feishu:save` |
| GET/POST | `/im/project/wechat/config`（含 `/group-test`、`/single-test`） | 企业微信配置与测试（`WeChatConfigResource`） | `wechat:query` / `wechat:save` |
| GET/POST | `/im/config` | 当前用户 IM 通知配置（`IMUserConfigResource`） | `notice:list` |
| DELETE | `/im/config/{imConfigId}` | 删除用户 IM 配置 | `notice:list` |
