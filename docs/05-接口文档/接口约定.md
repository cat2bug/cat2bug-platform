# 接口约定

前后端与第三方调用 Cat2Bug 后端（默认 Quarkus）时共同遵守的前缀、鉴权、响应结构、分页排序与错误码约定。

## 基础前缀

- 后端端口 `2020`，REST 资源位于 `cat2bug-platform-admin/src/main/java/com/cat2bug/admin/resource/`（JAX-RS `@Path`），无统一 context path。
- 前端 axios `baseURL` 取 `VUE_APP_BASE_API`：开发 `/dev-api`（Vite 代理到 `http://127.0.0.1:2020` 并去掉前缀；`/git/**` 同源直转后端），`production`/`cloud` 为 `/prod-api`，`staging` 为 `/stage-api`，embedded 为空串，见 `cat2bug-platform-ui/.env.*`、`cat2bug-platform-ui/vite.config.js`。
- 前端请求封装：`cat2bug-platform-ui/src/utils/request.js`；各业务 API：`cat2bug-platform-ui/src/api/`。

## 鉴权

| 场景 | 路径 | 方式 | 实现 |
|---|---|---|---|
| 标准登录 | 除下列外全部 | 请求头 `Authorization: Bearer <JWT>`（前缀常量 `TokenConstants.TOKEN_PREFIX = "Bearer "`，无前缀也能解析） | `cat2bug-platform-framework/.../security/JwtAuthFilter.java`、`TokenService.java` |
| Open API | `/api`、`/api/**` | 请求头 `CAT2BUG-API-KEY: <key>`（会剥掉 `Bearer ` 前缀）；需 `cat2bug.api.enabled=true`（Quarkus `application.properties` 默认 `true`） | `security/open/ApiKeyAuthFilter.java`、`ApiFeaturePermissionFilter.java` |
| Git Smart HTTP | `/git/p/{projectId}/{slug}.git/*`、`/{teamKey}/{projectKey}/code/{slug}.git/*` | HTTP Basic（平台用户名 + 密码），realm `Cat2Bug Git` | `GitSmartHttpResource.java` |

- 免登录路径（`security/PublicPaths.java`）：`/`、`/login`、`/logout`、`/register`、`/version`、`/captchaImage`、`/setup/**`、`/upgrade/**`、`/druid/**`（按 Cookie 自鉴权）、`/q/health*`、`/websocket/**`、`/profile/**`、`/system/defect/{id}/shard/**`、`/invite/{token}` 与 `/invite/{token}/preview`、`/system/report/template/preset/**/preview`。
- 权限：方法上 `@RequiresPermissions("system:defect:list")`，可 `value = {...}, logical = OR`；拥有 `*:*:*`（`SecurityConstants.ALL_PERMISSION`）视为全部权限，见 `PermissionAuthorizationFilter.java`、`PermissionChecker.java`。
- 前端登录后还会附带 `C2B_C0`/`C2B_C1`/`C2B_C2` 云端签名头（平台、签名、时间戳），用于云端接口校验；本地后端是否校验「待确认」。

## 响应结构

- `AjaxResult`（继承 `HashMap`）：`{"code":200,"msg":"...","data":...}`，登录接口额外返回 `token`。常量见 `cat2bug-platform-common` 的 `AjaxResult`：`HTTP_OK=200`、`HTTP_UNAUTHORIZED=401`、`HTTP_FORBIDDEN=403`、`HTTP_ERROR=500`、`HTTP_WARN=601`。
- `TableDataInfo`：`{"code":200,"msg":"查询成功","total":N,"rows":[...]}`，用于 `/list` 类接口。
- 导出接口多为 `POST .../export`，返回二进制流（Excel）；下载类接口 `Produces application/octet-stream`。

## 分页与排序

- 分页参数 `pageNum`、`pageSize`（Query）。
- 排序参数 `orderByColumn`、`isAsc`；由 `cat2bug-platform-framework/.../web/PageOrderFilter.java` 统一校验，非法时返回 HTTP 200 + `AjaxResult.error("参数不符合规范，不能进行查询")`（code 500）；超长时为「参数已超过最大限制，不能进行查询」。缺陷自定义字段排序列允许 `custom_` 前缀（`PageOrder.java`）。

## 错误码

`HttpStatus`（`cat2bug-platform-common/.../constant/HttpStatus.java`）：`SUCCESS=200`、`BAD_REQUEST=400`、`UNAUTHORIZED=401`、`FORBIDDEN=403`、`NOT_FOUND=404`、`CONFLICT=409`、`ERROR=500`。

- 标准 JWT 线：认证/授权失败返回 **HTTP 200** + JSON `code` 401（「请求访问：{path}，认证失败，无法访问系统资源」）或 403（「没有权限，请联系管理员授权」），见 `web/SecurityResponses.java`；前端 `request.js` 按 `code` 处理，401 弹重新登录，500 提示 `msg`。
- Open API 线：返回 **真实 HTTP 401/403** + `AjaxResult`，消息如「API KEY 不能为空」「无效的 API KEY」「API KEY 已禁用」「Open API 未启用」「无权限访问此资源」，见 `web/ApiSecurityResponses.java`。
- 前端默认文案：`cat2bug-platform-ui/src/utils/errorCode.js`（401/403/404/default）。

## 国际化

- 前端每个请求带自定义请求头 `language`（取 localStorage，默认 `zh_CN`），**不是** `Accept-Language`。
- Quarkus 端用 `LocaleUtils.parseLanguageHeader` 解析 `language`（如 `zh_CN`、`en_US`），目前已核实用于缺陷/用例 Excel 导入导出（`DefectResource`、`CaseResource`）；其它接口是否按语言返回消息「待确认」。
- `POST /{lang}`（`LanguagesResource`）仅为兼容桩，直接返回成功。

## WebSocket

- 地址：`ws://<host>:2020/websocket/{memberId}/message`（`websocket/MessageWebsocketEndpoint.java`），路径在免登录白名单内；开发环境前端走 `VUE_APP_BASE_WEBSOCKET`（默认 `/ws`）前缀，Vite 代理到 `ws://127.0.0.1:2020` 并去掉前缀。

## 文件上传与下载

- 上传：`POST /common/upload`（multipart，字段 `file`，可选 `customFileName`），返回 `url`、`fileName`、`newFileName`、`originalFilename`、`fileExtension`；批量 `POST /common/uploads`（字段 `files`，返回逗号拼接的 `urls`/`fileNames` 等）；截图 `POST /common/upload/screen-shot`（JSON）。
- 删除：`DELETE /common/delete`，JSON `{"fileName": ...}`。
- 下载：`GET /common/download?fileName=&delete=`、`GET /common/download/resource?resource=`；静态资源 `GET /profile/**`（`ProfileResource`，免登录）。
- 文件根目录 `cat2bug.profile`（默认 `./upload`），Git 仓库也在其下，部署须整体持久化。
- Open API 上传：`POST /api/file/upload`，见 [[接口清单-OpenAPI与AI]]。
