# Element Plus 表单项内容区横排挤开子块

- 日期：2026-10-30
- 涉及：后台

## 现象

工作日历弹框里「月历」下的年月导航、日期格、图例本应上下排列，实际被挤成左中右三列；暗色主题下还容易误用浅色实心底。

## 根因

`el-form-item` 的内容区默认是横向 `flex`。多个块级子节点会并排，而不是按文档流纵向堆叠。

## 解决办法

在表单项内容里包一层纵向容器（如 `display: flex; flex-direction: column; width: 100%`），再放导航 / 网格 / 图例。状态色用主题变量或半透明叠色，避免硬编码浅色底。

## 以后怎么避免

复杂控件放进 `el-form-item` 时，先假定内容区是横排 flex；需要纵向布局就显式包一层 column。
