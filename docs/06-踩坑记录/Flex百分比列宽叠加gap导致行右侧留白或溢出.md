# Flex 百分比列宽叠加 gap 导致行右侧留白或溢出

- 日期：2026-10-26
- 涉及：后台

## 现象

工作台多列行用 `flex: 0 0 N%` + `max-width: N%`，再加 `gap: 12px` 后，整行对不齐工具条右缘：要么右侧空一截，要么挤出滚动。

## 根因

百分比 flex-basis 按容器**全宽**解析，`gap` 再额外占宽，总和变成 `100% + (n-1)×gap`，与「比例合计 100%」的直觉冲突。

## 解决办法

列宽改为按 24 栅格 `span` 用 `flex: ${span} ${span} 0`（basis 0），让浏览器在扣掉 gap 后的剩余空间里按 grow 比例分配。

## 以后怎么避免

行内多列 + CSS `gap` 时，不要用「百分比之和 = 100%」当宽度真相；用 grow/fr 或 `calc((100% - gaps) * span/24)`。
