# 写死品牌色盖过主题 token，静态审查稿对不齐现网

- 日期：2026-10-17
- 涉及：前端

## 现象

改了 `theme-dark.scss` 的 `--cat2bug-primary` 之后，暗色下「新建用例」悬停仍是琥珀黄，页签和实心按钮也像两套蓝。用静态 HTML 对照缺陷列表时，工具区图标和布局对不齐现网，越改越偏。

## 根因

业务页和键盘焦点样式里写死了 `#409eff`、`#FFC107`、`#FFD54F`，优先级高于主题 token。静态稿无法复现 Element Plus 页签、拆分按钮和表格的真实结构，拿它验收会把语义色（收藏星、状态点）和品牌色搅在一起。

## 解决办法

品牌位改引用 `--cat2bug-primary` / `--cat2bug-accent`。复杂业务页在本地现网看浅色和暗色，静态稿只保留登录和壳色板。

## 以后怎么避免

新样式不要写死 `#409eff` 或 `#FFC107`。暗色悬停发黄时先搜这两个字面量。收藏星金黄和警告色不要改成品牌蓝。约定见 [[主题与配色]]。
