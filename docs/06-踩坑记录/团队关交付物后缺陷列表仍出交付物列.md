# 团队关交付物后缺陷列表仍出交付物列

- 日期：2026-11-04
- 涉及：后台（前端缺陷列表）

## 现象

团队模块页面设置关闭「交付物」后，侧栏交付物入口已消失，缺陷新建/筛选也不再要交付物，但表格 / Excel 仍显示「交付物」列。

## 根因

`hiddenDefectBuiltinFormKeys` 已把 `moduleId` 列入隐藏，但 `omitTeamGatedDefectColumns` 最初只过滤了用例列（`case` / `caseId`），未过滤 `module` / `moduleId`。列表列走后者。

## 解决办法

关 `deliverable` 时同步过滤 `key === 'module'`、`prop/key === 'moduleId'`（见 `utils/module-page-settings.js` 的 `omitTeamGatedDefectColumns`）。

## 以后怎么避免

团队闸门藏字段时，表单键与表格列键两套路径都要测；新增开关键时在 `omitTeamGatedDefectColumns` / `hiddenDefectBuiltinFormKeys` 成对补齐，并加单测。
