# 改项目路径键后菜单短暂 404

- 日期：2026-10-27
- 涉及：后台

## 现象

在项目基本信息里改「项目路径名」并保存后，点侧栏其它模块先到 404，过几秒（或整页刷新）才恢复。

## 根因

`updateProject` 只写了库，没有立刻：

1. `GetInfo` + `GenerateRoutes` 用新 `projectKey` 重写侧栏；
2. 把当前 History URL 从 `/{team}/{oldKey}/…` 换成新 key。

侧栏和地址栏仍指向旧 key，`ensureProjectScopedContext` → `getProjectByPathKeys` 查不到就进 `/404`。`goBack()` / `router.back()` 还会回到历史里的旧路径。

## 解决办法

路径键确有变更时，保存成功后走 `SwitchCurrentProject(projectId, { rewriteUrl: true })`，再 `replace` 到新 key 下的项目设置页；失败才整页 `go(0)` 兜底。

## 以后怎么避免

凡会改 `teamKey` / `projectKey` 的保存，必须同步刷新动态路由并改写当前命名空间 URL，不能只 toast + `back()`。
