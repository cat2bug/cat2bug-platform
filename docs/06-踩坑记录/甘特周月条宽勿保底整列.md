# 甘特周月条宽勿保底整列

- 日期：2026-10-30
- 涉及：后台

## 现象

按月（或按周）查看时，计划仅 1 天的缺陷条几乎占半列甚至整列，与列表「1 天」不一致。

## 根因

`barGeometry` 用 `Math.max(列宽, x2 - x)`：日尺度 1 天≈1 列合理，周/月列代表多天，短任务被强行拉满一列。CSS `min-width` 过大（如 28px）在月列约 96px 时也会把短条视觉拉宽。

## 解决办法

- 日尺度可保底一列；周/月只用真实 `x2 - x`，另设很小像素下限（如 4px）保证可点。
- 条上编号与名称拆开，编号不省略；窄条允许编号溢出显示。

## 以后怎么避免

凡「一列 = 多天」的尺度，条宽必须按日期比例算，禁止一律 `max(colWidth, …)`。
