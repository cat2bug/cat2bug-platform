# 甘特空态通底垫高挤出纵向滚动条

- 日期：2026-10-30
- 涉及：后台

## 现象

缺陷甘特无已排期数据时，左侧空状态旁仍出现纵向滚动条；时间轴也可能因横向滚动条再挤出纵向条。

## 根因

为与右侧轴「通底」对齐，左侧在 `axisContentHeight === 0` 时仍垫入整段 `axisFillHeight`（≈可视高度），空状态组件高度再叠上去，内容总高大于可视区。右侧把 `axis-body` 高度设成 `clientHeight` 后，宽时间轴出现横向滚动条，可视高度变矮，纵向又溢出。

## 解决办法

- 空态（`!groups.length`）不渲染左侧 fill；左侧 / 轴滚动容器空态关掉 `overflow-y`。
- 空态轴 body 用 `height: 100%` 铺底，不要写成「等于测量到的 clientHeight」像素值。

## 以后怎么避免

甘特或其它「内容垫高通底」布局：空态与有数据态分支处理；有横向滚动时不要用 clientHeight 硬编码内容高度。
