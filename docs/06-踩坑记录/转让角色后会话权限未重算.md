# 转让角色后会话权限未重算

- 日期：2026-11-04
- 涉及：后台 / 前端

## 现象

团队创建人转让成功后，库中角色已变，但原创建人继续操作仍像持有 `team.create-by`；前端调用 `getInfo` 也不掉权。

## 根因

菜单权限缓存在 `LoginUser` 会话里；`contextPermissionsMerged=true` 后 enricher 不再重算。`getInfo` 曾直接返回 `loginUser.getPermissions()`，未按当前团队角色刷新。

## 解决办法

角色变更写接口（如 `transfer-creator`）成功后调用 `SysPermissionService.updateRoleAndPermissionOfCurrentUser`；`getInfo` 返回前同样按当前上下文重算并写回 session。

## 以后怎么避免

凡改动 `sys_user_team_role` / 影响菜单权限的接口，成功路径必须刷新当前会话权限；不要假设前端重拉 `getInfo` 会自动读库。
