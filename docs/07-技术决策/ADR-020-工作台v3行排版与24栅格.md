# ADR-020 工作台 v3 行排版与 24 栅格

- 日期：2026-10-26
- 状态：已采纳（双页签「工作台 | 看板」条款被 [[ADR-021-工作台固定页与自定义私有共享页签]] 取代；v3 行排版与 24 栅格仍有效）

## 背景

项目落地页一期用组件列表、二期用 12 列自由栅格；编辑心智偏「贴磁贴」，难以表达「这一行几列、各占多宽」。产品尚未对外发布，允许 BREAKING 换配置模型。

## 候选方案

### 方案 A：继续 12 列自由栅格，编辑器伪装成行

优点：兼容已有 layout 字段。

缺点：双向同步成本高，与「比例一等公民」冲突。

### 方案 B：行（rows）+ 列槽（cols），列宽为同行相对比例 / 24 栅格整数 span

优点：与编辑心智一致；渲染与拖缝可统一约束；预设好写。

缺点：旧 v1/v2 配置不做字段迁移，直接套角色预设。

## 最终决定

采用方案 B：

- 配置 `version: 3`：`tabs.work.rows[]`，每行 `cols[]`（≤4），`ratio` 为 **24 栅格整数 span**（同行总和 24，单列 ≥ 2）；高度 `content` / `row` / `fixed(+px)`；列内组件为有序 `widgets[]`（同列 `type` 唯一，可上下堆叠；旧单字段 `widget` 读入时归一为一元素列表）。
- 查看/编辑列宽用 flex-grow 按 span 分配（扣除 gap），避免 `%` + `gap` 溢出或留白。
- 比例下拉只选预设；拖列缝按整数格吸附，并受组件 `minSpan` 约束。
- ~~页签保留「工作台 | 看板」~~ → 见 [[ADR-021-工作台固定页与自定义私有共享页签]]（去看板；固定工作台 + 自定义私有/共享页签；原看板组件进组件库）。
- 文档钉选 `document-pin`：列内只读渲染 Markdown 正文（标题栏可点进 `HandleMarkdownDocument`），不内嵌完整编辑器。

## 原因

行槽模型直接对应「设列数 → 调比例 → 放组件」；24 栅格与 Element 习惯对齐，且便于预设与拖拽一致。未发布允许丢弃旧 layout，避免双轨。

## 副作用

- 读到 `version < 3` 或无 `rows` 时重置为当前角色预设并写回。
- 原看板组件已并入工作台组件库（ADR-021）；`tabAffinity` 不再区分 board-only。
- 动态 Tab 延后，但布局字段与 `tabs.<id>.rows` 同构预留。
