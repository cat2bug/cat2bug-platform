# 1.0.0（2026-06-10）

记录 1.0.0 版本上线的主要内容。版本号提交 `9fc440f5`（chore(release): 前后端版本号升级至 1.0.0）。

## 主要内容

- 后端升级 Spring Boot 3.3.x + JDK 17（5 月）。
- 安装/升级向导：首次安装、Legacy 升级、安装配置收敛到 `application-install.yml`。
- 缺陷/用例 Excel 导入导出按表格列顺序生成模版，支持跨语言表头。
- 键盘快捷键体系（缺陷页、统计模版页、报告详情、交付物弹框等）。
- `Cat2BugTable` 表头拖序与调宽手柄。
- Spring Native 构建链、UPX 压缩与冒烟脚本（6 月中旬完成交付收尾，见 [[ADR-001-Spring-Native作为单文件交付线]]）。
