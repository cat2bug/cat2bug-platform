# 1.1.0（2026-07-13 起，当前版本）

记录 1.1.0 版本的内容。版本号提交 `f0e20695`（chore(release): 将平台版本升级至 1.1.0）；之后的功能仍沿用 1.1.0 版本号，按月见 [[2026-10]]。

## 主要内容

- 前端迁移 Vue 3 + Vite + Element Plus + Pinia（见 [[ADR-005-前端迁移Vue3-Vite-ElementPlus-Pinia]]）。
- 报告模版 Milkdown 编辑器与 DSL 往返、模版变量悬停预览、国标预制模版、报告详情三栏批注与历史恢复（见 [[ADR-009-报告模版编辑器用Milkdown且DSL为真相源]]）。
- 项目 Git 代码仓库：Smart HTTP、在线浏览、提交详情、分支与 PR、发行版与贡献者、成员与邀请、Webhook、设置、导入、标签（见 [[ADR-006-Git仓库用JGit自托管与Smart-HTTP]]）。
- 团队/项目路径键与项目级 History 路由（见 [[项目级History路由与路径键]]）。
- 7 月下旬曾退役 Quarkus 对照模块（见 [[ADR-002-退役Quarkus交付改以Spring为默认]]），10 月恢复。
