# 1.1.1（2026-10-21 起，当前版本）

平台版本号由 1.1.0 升级至 1.1.1。Maven `cat2bug.version`、前端 `package.json`、`application.properties` 的 `cat2bug.version` 同步为 1.1.1。

## 主要内容

- 项目落地页「工作台」：角色预设、组件显隐/排序与 v3 行排版、私有/共享自定义页签、组件库分组预览与搜索、成员本周贡献等（见 [[2026-10]]、`project-workbench` 及后续 workbench-* 变更）。
- 用例类型、评审纪要模板、缺陷属性升到团队设置；仅团队创建人/管理员可配（变更 `team-case-defect-settings`，见 [[ADR-023-用例类型评审模板与缺陷属性归属团队]]）。
- 缺陷列表批量操作（指派 / 修复 / 驳回 / 通过 / 关闭 / 重开 / 删除），OpenSpec 变更 `defect-batch-operations`。
- 承接 1.1.0 以来按月合入的能力（见 [[2026-10]]），不再沿用 1.1.0 作为当前版本号。源码管理（Git）能力见 [[1.1.0]]，本版未单独当作新功能宣传。
