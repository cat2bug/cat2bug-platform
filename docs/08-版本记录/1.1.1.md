# 1.1.1（2026-10-21 起，当前版本）

平台版本号由 1.1.0 升级至 1.1.1。Maven `cat2bug.version`、前端 `package.json`、`application.properties` 的 `cat2bug.version` 同步为 1.1.1。

## 主要内容

- 缺陷列表批量操作（指派 / 修复 / 驳回 / 通过 / 关闭 / 重开 / 删除），OpenSpec 变更 `defect-batch-operations`。
- 承接 1.1.0 以来按月合入的能力（见 [[2026-10]]），不再沿用 1.1.0 作为当前版本号。
