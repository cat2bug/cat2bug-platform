# 1.2.0（2026-10-29 起，当前版本）

平台版本号由 1.1.1 升级至 1.2.0。Maven `cat2bug.version`、前端 `package.json`、`application.properties` 的 `cat2bug.version` 同步为 1.2.0。开发在分支 `1.2.0`（worktree `.worktree/1.2.0`）上进行。

## 主要内容

- 版本线切换：自此以 1.2.0 作为后续新版本开发基线；1.1.1 能力与文档见 [[1.1.1]]、[[2026-10]]。
- 缺陷列表第三视图「甘特」：与表格/Excel 同级切换；处理人/交付物分组（交付物树序缩进）、日周月尺度、未排期池拖入排期；无新 ADR（自研一期实现，见 OpenSpec `defect-list-gantt-view`）。
- 甘特二期：FS 依赖、关键路径、处理人负荷、项目活跃基线、框选批量平移（变更 `defect-list-gantt-phase2`，无新 ADR）。
- 新建缺陷「免填」明确不含描述；描述与表单双向同步，连续新建后描述区清空（变更 `defect-add-cache-exclude-describe`）。
