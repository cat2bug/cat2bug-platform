# 1.2.1（2026-11-04 起，当前版本）

平台版本号由 1.2.0 升级至 1.2.1。Maven `cat2bug.version`、前端 `package.json`、`application.properties` 的 `cat2bug.version` 同步为 1.2.1。

## 主要内容

- 缺陷 Excel / 看板增加左侧交付物过滤侧栏（与表格同语义；含子节点筛选；分视图显隐缓存；变更 `defect-module-tree-excel-kanban-gantt`）。
- 出站选择性分包同步与同步页体验完善（文档树图标、空 Markdown 补文件等）。
- 新建/编辑项目成员下拉：暗色悬停、限高滚动，并隐藏已选成员。
