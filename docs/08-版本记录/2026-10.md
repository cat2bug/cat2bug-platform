- 列表排序与 Spring 对等、计划项 `defect_ids` CSV 修复、系统管理员对 Git 仓库全权限、文档菜单图标补回（`59f6a23e`，见 [[列表排序与注入防护]]、[[计划项缺陷ID的CSV存储]]、[[ADR-008-系统管理员对Git仓库全权限]]）。
- 建立 `docs/` 长期知识库。
- 移除 Spring 后端并统一模块命名（变更 `retire-spring-and-unify-modules`，见 [[ADR-010-移除Spring后端并统一模块命名]]、[[ADR-011-内部资料入私有库公开发布按清单剔除]]）：

  - `4608c36e` 包名改名：`com.cat2bug.quarkus.*` → `com.cat2bug.*`，`quarkus.application.name=cat2bug-admin`。

  - 依赖：去掉 Spring BOM 后补 `commons-pool2 2.12.1`、`jakarta.websocket-client-api 2.1.1` 的版本管理，jedis 由 5.0.2 变为 5.1.5，见 [[去掉Spring-BOM后传递依赖版本漂移]]。
  - 验证：全量测试 162 个通过；JVM 单 JAR 冒烟（登录 / 项目 / Git 浏览 / 预制模版）与 Compose 冒烟（安装 → 上传 → 建仓 → 重建后端容器后数据仍在）通过。

  - 实施中的坑：[[Quarkus数据源db-kind是构建期属性]]、[[改目录名后gitignore旧规则失效导致敏感配置暴露]]、[[被引用文件未跟踪导致干净克隆编译失败]]、[[旧版运行期配置与命名数据源不兼容导致登录500]]、[[Native冒烟默认模式缺少数据源时复用空库导致项目检查失败]]。
- 补齐与 Spring 线的剩余行为差异（变更 `close-spring-parity-gaps`，见 [[ADR-012-用户内容在前端渲染时清洗而非后端转义]]、[[权限模型与鉴权链路]]）：
  - `8fbedbd4` 前端 XSS：新增依赖 `dompurify`，Markdown、评论、`Cat2BugText`、云端用例提示词、命令面板、通知提醒、导入结果等 `v-html` 统一经 `sanitizeHtml` / `escapeHtml`；图片失败回退改为捕获阶段监听，不再用内联 `onerror`。后端不恢复全局转义。
  - `0ff9cb2d` 数据权限：用户 / 部门列表与单条操作按角色数据范围（全部 / 自定义 / 本部门 / 本部门及以下 / 仅本人）过滤，超级管理员不受限，角色列表不过滤。**行为变化**：数据范围不是「全部」的角色，登录后看到的用户、部门列表会比之前少，越权查看 / 修改其它部门用户会被拒绝。

  - 验证：全量测试 181 个通过（2 个 MySQL 真库测试默认跳过）；前端单测 448 个通过、`build:prod` 通过。Native 重建与冒烟待合并后执行。
