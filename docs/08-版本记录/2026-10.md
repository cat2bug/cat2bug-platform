# 2026-10

记录 2026 年 10 月合入 `core` 分支的内容。月中仍沿用 1.1.0 版本号；2026-10-21 起产品版本升为 [[1.1.1]]。

## 主要内容

- 项目落地页改为可定制「工作台｜看板」（变更 `project-workbench`）：角色预设、组件显隐/排序、用户×项目持久化（`GET/PUT /system/workbench/{projectId}`，迁移 `V1_1_0_47`）；工作台侧重个人/团队待办与统计，看板为可开关的项目级统计组件；二期自由栅格（`version:2` + 12 列拖位置/改尺寸，小屏纵向回退）曾落地。见 [[产品定位与核心功能]]、[[接口清单-系统与监控]]。
- 工作台三期行排版（变更 `workbench-phase3-row-layout`，见 [[ADR-020-工作台v3行排版与24栅格]]）：配置升级为 `version:3` 的 `rows/cols`（24 栅格 span、高度三态）；行编辑器拖入+指定；钉选 Markdown。未发布，旧 v1/v2 套预设不迁字段。见 [[产品定位与核心功能]]。
- 工作台自定义页签（变更 `workbench-custom-tabs`，见 [[ADR-021-工作台固定页与自定义私有共享页签]]）：去掉看板；「工作台」+ 私有/项目共享自定义 tab（共享≤24）+ 加号；同组内可拖拽改序（`PUT .../tabs/sort`）；可见页签>1 时可删（含工作台本地隐藏），仅剩 1 个不可删；钉选文档列内预览正文；个人布局与自定义分表；原看板组件进组件库。见 [[产品定位与核心功能]]、[[接口清单-系统与监控]]。
- 动作控件点击后灭野生焦点环（变更 `suppress-action-focus-ring`）：全局样式处理按钮/页签/侧栏等，表单聚焦环与键盘导航 class 高亮保留。见 [[组件与交互约定]]。
- 缺陷列表批量操作（变更 `defect-batch-operations`）：勾选后批量指派/修复/驳回/通过/关闭/重开/删除；资格按状态集合严格计算，串行提交汇总结果。
- 缺陷列表自定义页签对齐工作台悬停操作（变更 `defect-list-tab-edit-actions`）：悬停显示编辑/删除；编辑复用创建对话框并走 `PUT /system/tabs`。见 [[组件与交互约定]]。
- 平台版本升级至 [[1.1.1]]（Maven / 前端 package / `cat2bug.version` / README / 首页更新日志同步）。

## 主要内容（续）

- 用例类型与可选评审（变更 `case-type-and-review`，版本仍为 1.1.0）：项目字典 `sys_case_type`（新项目与已有项目种子为功能 / 接口 / 界面），`sys_case.case_type` 可空；评审是勾选批次（`sys_case_review`），完成后生成 Markdown 纪要并写下 `review_status`。测试计划只把类型和评审当筛选项。MCP 挂在已有 case / project 模块。迁移 `V1_1_0_45`。
