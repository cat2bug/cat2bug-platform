# 2026-10

记录 2026 年 10 月合入 `core` 分支的内容（版本号仍为 1.1.0，尚未发布新版本）。

## 主要内容

- 恢复 Quarkus 为默认后端，并与 Spring 线功能全量对等；Native 体积约 38.8 MiB 被接受（`6115f189`，见 [[ADR-003-恢复Quarkus为默认后端-Spring保留为回滚线]]、[[ADR-004-Native交付分两道门并接受约38MiB]]）。
- 列表排序与 Spring 对等、计划项 `defect_ids` CSV 修复、系统管理员对 Git 仓库全权限、文档菜单图标补回（`59f6a23e`，见 [[列表排序与注入防护]]、[[计划项缺陷ID的CSV存储]]、[[ADR-008-系统管理员对Git仓库全权限]]）。
- 建立 `docs/` 长期知识库。
- 移除 Spring 后端并统一模块命名（变更 `retire-spring-and-unify-modules`，见 [[ADR-010-移除Spring后端并统一模块命名]]、[[ADR-011-内部资料入私有库公开发布按清单剔除]]）：
  - `fcaab5d5` 删除 Spring 后端：9 个 Spring 模块、`quarkus-spike`、Spring Native 交付物、`deploy/test`、`readme/spring-native-delivery`、`vue.config.js`；删前打本地 tag `spring-final-1.1.0`（未推送）。代码生成器 `/tool/gen` 随之移除。
  - `82440389` 模块改名：目录 `cat2bug-platform-quarkus-*` → `cat2bug-platform-*`，artifactId `cat2bug-quarkus-*` → `cat2bug-*`，根 pom 默认 reactor 即产品构建（不再需要 `-Pquarkus`）；脚本改为 `build-embedded.sh`、`build-native.sh`、`run-jar.sh`、`deploy/docker/build.sh`、`deploy/ci/native.yml`。
  - `4608c36e` 包名改名：`com.cat2bug.quarkus.*` → `com.cat2bug.*`，`quarkus.application.name=cat2bug-admin`。
  - `543c1085` 交付链：前端只留 `build:embedded`；Docker 后端改跑 MySQL 版单 JAR（只支持 MySQL），卷 `./uploadPath:/home/uploadPath` 与 `CAT2BUG_PROFILE` 对齐并新增 `./config:/home/config`；rpm 改为打包 Native ELF（`build-rpm.sh`）；安装向导把「存在但无成功迁移」的 MySQL 库按新库建表；`run-jar.sh` 传 `-Dcat2bug.install.config-path` 修复安装状态误判。见 [[部署]]、[[安装向导把预建空MySQL库判为existing]]。
  - `63dc1a4f` 内部资料入私有库：`docs/` 取消忽略；新增 `deploy/public-release-exclude.txt` 与 `deploy/scripts/export-public.sh` 生成公开发布提交 `public/master`。
  - `c24dd4b0` `README.md`、`deploy/README.md`、`deploy/docker/README.md` 改为单后端与新脚本名。
  - 依赖：去掉 Spring BOM 后补 `commons-pool2 2.12.1`、`jakarta.websocket-client-api 2.1.1` 的版本管理，jedis 由 5.0.2 变为 5.1.5，见 [[去掉Spring-BOM后传递依赖版本漂移]]。
  - 验证：全量测试 162 个通过；JVM 单 JAR 冒烟（登录 / 项目 / Git 浏览 / 预制模版）与 Compose 冒烟（安装 → 上传 → 建仓 → 重建后端容器后数据仍在）通过。
  - Native：arm64 重建 UPX 前 177,218,544 字节（约 169.0 MiB）、UPX 后 40,709,592 字节（约 38.8 MiB），与改名前一致；`smoke-native-docker.sh arm64` 默认模式与 `FRESH=true` 两种冒烟通过；Native 容器内浏览器回归缺陷 / 用例 / 计划 / 报告 / 文档 / 代码仓库 / 系统管理 / 系统监控 18 个页面，无失败请求与错误提示。
  - 实施中的坑：[[Quarkus数据源db-kind是构建期属性]]、[[改目录名后gitignore旧规则失效导致敏感配置暴露]]、[[被引用文件未跟踪导致干净克隆编译失败]]、[[旧版运行期配置与命名数据源不兼容导致登录500]]、[[Native冒烟默认模式缺少数据源时复用空库导致项目检查失败]]。
- 补回 IM 外部推送（变更 `restore-im-external-push`，见 [[IM多渠道推送]]）：缺陷变更、发送通知、报告新建（新增站内通知）推送到钉钉 / 飞书 / 企业微信的个人消息与群机器人，以及邮件（Quarkus Mailer，默认关闭，凭据只来自运行期配置）；外部渠道走 3 线程池异步发送，单渠道失败不影响业务与其它渠道；推送链接改为 History 路由。验证：全量测试 191 个通过（跳过 2），JVM 单 JAR 冒烟通过；真实平台账号待验证。坑：[[Quarkus-Mailer的host默认localhost]]、[[后端拼的Hash链接在History路由下落到首页]]。
- 补齐与 Spring 线的剩余行为差异（变更 `close-spring-parity-gaps`，见 [[ADR-012-用户内容在前端渲染时清洗而非后端转义]]、[[权限模型与鉴权链路]]）：
  - `8fbedbd4` 前端 XSS：新增依赖 `dompurify`，Markdown、评论、`Cat2BugText`、云端用例提示词、命令面板、通知提醒、导入结果等 `v-html` 统一经 `sanitizeHtml` / `escapeHtml`；图片失败回退改为捕获阶段监听，不再用内联 `onerror`。后端不恢复全局转义。

  - 验证：全量测试 181 个通过（2 个 MySQL 真库测试默认跳过）；前端单测 448 个通过、`build:prod` 通过。Native 重建与冒烟待合并后执行（结果见下一条）。
