# member-invite-and-project-access 手工测试清单

## 邀请链接（阶段 1）

### 团队邀请链接

1. 以团队管理员登录，进入 **团队 → 成员管理 → 邀请成员 → 邀请链接**。
2. 选择团队角色，点击生成链接；确认有效期约 1 小时、可复制 URL。
3. 在隐身窗口打开链接：未登录应跳转登录；登录后应成功加入团队。
4. 用另一账号打开同一链接：应能依次加入（多人共用）。
5. 撤销链接后再次打开：应提示已撤销/无效。
6. 等待 1 小时后打开：应提示已过期。

### 项目邀请链接

1. 进入 **项目 → 成员 → 添加成员 → 邀请链接**，生成项目链接。
2. 用非团队成员账号接受：应成为项目成员且 **不** 写入团队成员。
3. 已是项目成员再次打开：应提示已是成员。

## 项目成员解耦（阶段 2）

1. 准备用户 A：已注册但 **不在** 目标团队。
2. 项目管理员在添加成员中搜索 A：应能搜到并添加。
3. 用户 A 仅通过项目邀请加入后登录：
   - 左上角显示团队名（只读），不可切换团队。
   - 侧栏无团队项目列表、团队设置入口。
   - 可访问已授权项目菜单（缺陷、用例等）。
4. 用户 A 直链访问团队设置 URL：前端 404 或后端 403。

## API 冒烟

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/invite/{token}/preview` | 无需登录 |
| POST | `/invite/{token}/accept` | 需登录 |
| POST | `/system/team/{id}/invite-link` | 需 `system:team:member:invite` |
| GET | `/system/team/{id}/invite-links` | 活跃链接列表 |
| POST | `/system/project/{id}/invite-link` | 对称 |

## 回归

- 团队「搜索添加」即时邀请仍可用。
- 团队成员仍可正常切换团队、管理团队。
