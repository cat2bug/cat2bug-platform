## Why

源码管理列表目前只有仓库卡片与工具栏，缺少项目级「一眼概览」。用户需要在同一页看到仓数、开放 PR、关注合计、语言分布与项目成员，而不必逐仓点进详情。

## What Changes

- 在项目「源码管理」列表页宽屏右侧增加概览侧栏（对齐常见托管站概览面板，适配本平台语义）
- 侧栏展示三项统计：**仓库**（本项目仓数）、**PR**（本项目所有仓 open PR 合计）、**关注**（本项目所有仓被收藏次数合计）；**不**展示 Fork
- 侧栏展示 **仓库语言**：按文件扩展名轻量扫描各仓默认分支，汇总百分比（Top N +「其他」）；同步扫描并设上限，避免拖垮列表首屏
- 侧栏展示 **成员**：当前项目成员头像与名称（复用项目成员能力）
- 窄屏（约 `<1200px`）隐藏侧栏，仅保留列表
- 新增项目级 overview API，供侧栏一次拉取统计与语言分布；列表内切换关注后侧栏关注数即时更新

## Capabilities

### New Capabilities

- `git-repo-project-overview`: 项目级源码概览（仓库/PR/关注统计、轻量语言分布、列表页右侧栏 UI 与窄屏隐藏）

### Modified Capabilities

- （无）现有能力需求级不变；本 change 为净新增概览面，列表页布局增强挂在新能力下

## Impact

- **后端**：项目级 overview 聚合（仓数、open PR 数、`sys_user_git_repository` 关注合计）；JGit 默认分支文件路径按扩展名统计（带每仓/总文件扫描上限）；鉴权与现有项目 Git 读权限一致
- **前端**：`git/repo/index.vue` 双栏布局 + 侧栏组件；i18n；关注切换后刷新关注计数；CSS 媒体查询隐藏侧栏
- **数据**：无新业务表（MVP）；语言结果可不落库，请求时计算（上限内）
- **非目标**：Fork、GitHub 式公开 star、linguist 完整规则、语言结果持久化缓存、跨项目全局统计
