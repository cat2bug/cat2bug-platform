## Context

主题 token 已是 `#1890ff` / 暗色链接 `#69b1ff`。样式里的回退色和写死色仍指向 `#409eff` 与琥珀黄。

## Goals / Non-Goals

**Goals:**

- 品牌位不再出现 `#409eff`、`#FFC107`、`#ffce3a`、`#FFD54F`。
- CSS 能用变量的地方用 `var(--cat2bug-primary, #1890ff)`；画布和主题默认值用 `#1890ff`。

**Non-Goals:**

- 不改收藏星 `rgb(247, 186, 42)`、警告色、成功色、危险色。
- 不改验证码太阳/花芯、Markdown 引用块、项目预设图标插画。
- 不改控件尺寸和表格交互。

## Decisions

### 回退色只更新色值，不套两层 var()

`var(--cat2bug-primary, #409eff)` 的回退改为 `#1890ff`。已经在 `var()` 里的色值不再包一层变量。

### 插画琥珀保留

预设项目图标和验证码里的黄是图形本身，不是按钮悬停。

## Risks / Trade-offs

- [个别组件把警告黄和品牌黄写在一起] → 清扫后抽查邀请页和命令面板，确认按钮是蓝、警告仍是黄。

## Migration Plan

1. 批量替换品牌字面量。
2. 浅色、暗色各看缺陷列表、用例列表、邀请页。
3. 回退：还原本次样式 diff。
