## Context

前端是 Vue 3.5 + Vite 6 + Element Plus 2.9 + Pinia。主题 token 在 `cat2bug-platform-ui/src/assets/styles/theme-dark.scss`：`:root` 为浅色，`html.dark` 为暗色。浅色 `--cat2bug-primary` 为 `#409eff`，Element Plus 编译主色为 `#1890ff`，暗色品牌色为 `#FFC107`。控件高度 32px、圆角 4px 已全站统一。暗色对比度以 `.cursor/rules/ui-dark-theme-contrast.mdc` 为准。

本次只收观感。包体积是约束：不新增图片、字体和图标库。帮助文档大图和其他说明截图留到后续。

## Goals / Non-Goals

**Goals:**

- 两套主题共用品牌蓝 `#1890ff`，暗色链接与聚焦环用 `#69b1ff`。
- 侧栏、顶栏、页签的激活色与表面色走现有 token。
- 登录页只改按钮、链接和焦点色。猫场景、Z 字气泡、老鼠与方向键、像素验证码、语言图标、快捷键提示全部保留。
- 缺陷列表通过 token 继承新主色，作为业务页验收。
- 回写 `docs/04-UI规范/主题与配色.md` 的主色约定。

**Non-Goals:**

- 不重写 150 个业务页，不替换 Element Plus，不上 Tailwind。
- 不改 `Cat2BugTable` 的拖序、固定列、调宽和排序。
- 不改控件高度、圆角、权限、路由、接口、键盘保留字。
- 不改 Java 后端。
- 不处理项目封面（`replace-project-preset-icons`）和云端迁移（`migrate-cloud-to-quarkus`）。
- 不在本变更压缩帮助文档图、`401.gif`、钉钉/微信说明截图。
- 不新增 ADR。

## Decisions

### 品牌蓝用 `#1890ff`，不另选色相

Element Plus 已经按 `#1890ff` 编译。把它同时写入 `--cat2bug-primary`，浅色不再保留第二枚 `#409eff`。另选青绿或紫色会让现有按钮、文档截图和「浅色禁止金色悬停」的约定一起失效。

备选：继续以 `#409eff` 为唯一主色，并改 Element 编译色。未采用，因为要改 Sass 编译入口，收益只是换成另一枚相近的蓝。

### 暗色交互文字单独提亮

实心按钮仍用 `#1890ff` 配浅色字。链接和聚焦环在暗色底 `#252529` 上用 `#69b1ff`。若链接也用 `#1890ff`，在深底上对比不够。琥珀黄不再映射到 `--cat2bug-primary` 或 `--el-color-primary`。

备选：暗色整站继续用琥珀黄。未采用，两套主题会继续像两个产品。

### 品牌蓝只管品牌位，语义色不动

改色范围：主按钮、菜单/页签激活、文字链接、聚焦环。不改：收藏星（金黄 `rgb(247,186,42)`）、成功/警告/危险、统计卡片内多色条与状态点、缺陷状态标签、插画（猫场景月亮等）。审查稿不得把上述语义色一律刷成蓝。

### 只改 token 和壳子，业务页靠变量继承

侧栏、顶栏、页签、按钮悬停改为引用 `--cat2bug-primary` 与现有表面 token。已经使用这些变量的页面会一起变色。Vue 里写死的 `#409eff` / `#FFC107` 不在本变更逐文件清扫；清扫留到观感确认之后。

### 登录页保留特色，只换品牌色

2026-10-17 的示意图把登录收成居中白卡片，比现有页面差，已作废。猫场景、Z 字气泡、可操控老鼠、像素验证码和语言图标是产品识别，不删除、不换成纯色块。登录按钮和链接改用 `#1890ff`（暗色链接 `#69b1ff`），构图不动。

### 缺陷列表只做验收

打开缺陷列表，确认主操作是品牌蓝、暗色文字仍可读、表头手柄行为不变。不改 `Cat2BugTable` 源码，除非验收时发现它写死了品牌黄。

## Risks / Trade-offs

- [业务页仍有写死颜色] → 本变更明确只保证 token、壳子、登录和缺陷列表。后续单开清扫，避免和封面、云端变更抢文件。
- [登录 DOM 被误改] → 本变更不改登录模板结构，只改颜色变量。键盘 e2e 不应因插画节点消失而失败。
- [暗色对比度回退] → 新颜色只替换主色和聚焦环；文字、背景、边框继续用已有 token。改完在暗色下看登录、侧栏、缺陷列表和弹窗。
- [`#1890ff` 上的白字对比有限] → 与当前浅色实心按钮同一量级。本变更不把按钮改成深色字，以免和 Element Plus 默认按钮不一致。

## Migration Plan

1. 对齐 `element-plus-variables.scss` 与 `theme-dark.scss` 的主色和暗色聚焦环。
2. 改侧栏、顶栏、页签里仍指向琥珀黄或第二枚蓝的规则。
3. 登录页不改结构。浅色与暗色各确认猫场景、老鼠、验证码仍在，且登录按钮是品牌蓝。
4. 暗色与浅色各看一次壳子和缺陷列表。
5. 更新 `docs/04-UI规范/主题与配色.md`。
6. 回退：还原上述样式与登录引用即可，无数据迁移。
