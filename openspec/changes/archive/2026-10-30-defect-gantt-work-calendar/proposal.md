## Why

甘特排期、自动排列与拖动避让目前按**自然日**推进，周末与法定假日仍占工期，和国内「工作日排期」习惯不符；轴上仅有周末底纹，没有可编辑的工作日历。自动排列相关变更曾把工作日历列为 Non-Goal，能力补齐后再上日历，排出来的计划才可信。

## What Changes

- **项目工作日历**：每项目一份可编辑日历（OmniPlan 风格）——可配工作周（默认周一～五）、按年维护例外日（假日 / 调休上班）；支持从产品内置「中国法定」底表按年导入，并可手工改公司假、补班等。
- **工期语义改为工作日**：甘特条「天数」、默认落池工期、拖边改期的最小工期，均按工作日计；自然起止仍存库，由工作日推算。
- **排期动作一律遵守日历**：自动排列（`levelDefectPlans`）、拖动避让（`pushOverlapsAfterPinned`）、手工拖条/改边、FS「次日」起算，均只在工作日上落点与推进；可选「本次忽略日历」（仅一键自动排列预览）以便加班赶工。
- **缺年假日表可降级**：某年无例外数据时，仅按工作周跳非工作日，并提示「该年假日未配置」；**不做**强依赖外网实时 API。
- **轴与负荷可视化**：日轴除周末外可区分假日底纹与调休上班标记；负荷轨对非工作日不按占用计（或灰显），避免「空周末却像过载」。
- **存量计划**：不自动改写已有 plan 起止；新拖 / 自动排列 / 避让才用新规则。图层「天数」文案标明工作日。
- **不做**：个人班次、半天粒度、多时区、团队级日历模板（可后补「从模板复制」）、服务端求解器、自动批量「按工作日重算存量结束日」。
- **BREAKING**：无 API 破坏；产品语义上「计划天数」从自然日变为工作日（存量条显示天数可能变化，起止不变）。
- **不推翻**既有 ADR；属甘特与项目设置扩展。若沉淀「项目日历为排期唯一真相源」可另补 ADR，非本变更硬性要求。

## Capabilities

### New Capabilities

- `project-work-calendar`: 项目工作日历的数据模型、读写与编辑（工作周、年例外含假日/调休）、内置中国法定底表按年导入、缺年降级提示；供甘特与其它排期消费

### Modified Capabilities

- `defect-list-gantt-view`: 轴底纹（假日/调休）、拖放与改期按工作日、天数展示与日历入口
- `defect-gantt-level-resources`: 一键自动排列在工作日上 ASAP / 消空档 / 守 FS
- `defect-gantt-auto-level`: 拖动避让后推在工作日上推进并保留工作日工期
- `defect-list-gantt-phase2`: 负荷轨与非工作日占用展示约定

## Impact

- 后端：项目日历存取（Flyway 表或项目设置 JSON）、内置/导入假日资源、权限对齐项目设置（`project.create-by` / `project.admin` 可编）；甘特仍写缺陷 plan 字段。
- 前端：日历编辑 UI（项目设置或甘特图层入口）、`defect-gantt.js` 工作日原语（`isWorkday` / `addWorkdays` / `nextWorkday`）、`gantt.vue` 轴样式与排期路径、i18n、单测。
- 文档：`docs/04-UI规范`、`docs/05` 接口清单、`docs/08` 当月；长期「工作日语义」可写入 `docs/03` 或 ADR（实现时再定）。
- 关联：已归档的 `defect-gantt-auto-level` / `defect-gantt-level-resources`（日历为其显式后续）。
