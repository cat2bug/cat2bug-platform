## Context

缺陷页已用 `defectContentComponent` 在 `DefectTable` / `DefectExcel` 间切换，并共用页签与筛选。缺陷实体已有 `planStartTime`、`planEndTime`、`handleBy`（必填）、`moduleId`、状态枚举。历史上曾有日历视图后删除。产品希望一期提供 OmniPlan 风格的排期甘特，自研实现，避免 GPL/商用库与 MIT 仓库冲突。

## Goals / Non-Goals

**Goals:**

- 第三视图「甘特」：左列表 + 右时间轴，日/周/月尺度，今日线与周末底色。
- 上区已排期、下区未排期池；拖入默认 1 天；拖条/拉边改期写回。
- 分组可切换处理人 / 交付物（默认处理人）；处理人模式下多人镜像 + 重复图标。
- 拖到处理人组改处理人为该人；拖到交付物组改 `moduleId`；轴空白只改期。
- 条色使用现有 `--defect-state-*` token。
- 与页签/筛选一致；视图与分组偏好本地记忆。

**Non-Goals:**

- 依赖、里程碑、关键路径、资源负荷、基线、框选批量、空白处拖新建。
- 引入 dhtmlx/Bryntum 等 GPL 或商用甘特库。
- 新增「未指派」泳道（处理人必填）。
- 左列展示起止文字列。

## Decisions

1. **自研壳，不引整库甘特**  
   - 左：虚拟列表（分组头 + 行）；右：SVG/Canvas 时间轴；纵向滚动同步。  
   - 备选否决：frappe-gantt（缺泳道/未排期）、dhtmlx 免费版（GPL）、vis-timeline 整库（左表对齐仍要自研，一期直接自研更干净）。

2. **数据范围 = 当前页签筛选结果**  
   - 复用现有 list 查询；甘特可提高 `pageSize` 或前端按当前结果集渲染（实现时选一种并在 tasks 落地）。改期/改人/改交付物走现有缺陷更新 API，权限同编辑。

3. **处理人镜像行**  
   - 同一 `defectId` 多行仅展示；任意镜像行改期同步全部；改处理人为单人后其它镜像消失。重复图标悬停列出其他处理人。

4. **拖放语义**  
   - 未排期 → 轴：写入起止（落点日为开始，时长 1 天；若拖到处理人/交付物行则同时改对应字段）。  
   - 已排期条中部拖：平移时长不变；拉边：改一端，最小时长 1 天（日尺度）。  
   - 拖到处理人行：`handleBy = [该用户]`（替换，非追加）。  
   - 拖到交付物行：只改 `moduleId`。  
   - 拖到轴空白：只改日期。

5. **组件挂载点**  
   - `index.vue` radio 增加 `DefectGantt`；实现放在 `views/system/defect/list/gantt*`（或 `components/Defect/Gantt*`），样式跟缺陷页控件轨与状态色 token。

6. **不新增 ADR**  
   - 自研甘特为一期产品实现选择，未形成跨版本强制架构约束；若二期引入商用库再单开 ADR。

## Risks / Trade-offs

- [大数据量滚动/缩放卡顿] → 虚拟列表 + 轴只绘可视窗口；必要时限流 list pageSize 并提示筛选。  
- [多人镜像与「替换处理人」误操作] → 松手前可用轻量确认或明确落点高亮；悬停说明「将处理人设为某某」。  
- [交付物树层级深] → 按 `modulePath`（`/` 分隔）树序排列并左侧缩进；缺路径时拉 `/system/module/path-list` 补齐，并为中间祖先补占位组；不做树内跨交付物拖拽。  
- [Excel/表格改期与甘特不同步] → 切换视图时重新拉列表或监听同一查询结果。

## Migration Plan

- 纯前端能力 + 既有写接口；无库迁移。  
- 回滚：隐藏甘特 radio / 不合并该变更即可。
