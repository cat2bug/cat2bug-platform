## Why

缺陷已有计划开始/结束时间与处理人，但列表只有表格与 Excel，无法像 OmniPlan 那样按时间轴排期、拖拽改期与按人/交付物泳道查看。需要在缺陷页增加甘特视图，与现有视图切换并列，提升排期可视与操作效率。

## What Changes

- 缺陷页「表格 / Excel」切换旁新增「甘特」视图；模式本地记忆，共用当前页签与筛选。
- 自研甘特（左列表 + 右 SVG 时间轴）：日/周/月尺度、今日线、周末底色；条颜色默认跟缺陷状态 token。
- 已排期在上、无计划时间在下「未排期」池；可从池拖入时间轴（默认时长 1 天），也可拖条平移/拉边改期并写回。
- 分组可切换「处理人」或「交付物」（默认处理人）；按处理人时多人处理人在各泳道镜像显示并带重复提示图标。
- 拖到某处理人分组行：计划时间按落点写入，**处理人替换为该人**；拖到某交付物分组行：改 `moduleId`，不改处理人；拖到轴空白：只改日期。
- 一期不做：依赖线、里程碑、关键路径、资源负荷、基线、框选批量、空白拖新建。
- 不引入 GPL/商用甘特库；不推翻现有 ADR。

## Capabilities

### New Capabilities

- `defect-list-gantt-view`: 缺陷列表甘特视图的入口、布局、分组、未排期池、拖拽改期/改处理人/改交付物与状态着色

### Modified Capabilities

- （无）现有 `defect-list-tabs` 等规格不改需求语义；甘特仅复用其页签筛选结果作为数据范围

## Impact

- 前端：`views/system/defect/index.vue` 视图切换；新增 `list/gantt`（或等价）组件与工具条；复用缺陷列表 API 与更新接口写回 `planStartTime` / `planEndTime` / `handleBy` / `moduleId`。
- 后端：优先复用现有缺陷更新接口；若甘特需按时间窗拉取更大结果集，可后续加查询参数（非本期硬性）。
- 文档：`docs/04-UI规范/组件与交互约定.md` 补缺陷视图切换约定；版本记录在实现合入后回写。
