## ADDED Requirements

### Requirement: 测试计划新建与编辑为项目内整页

系统 MUST 在路径 `/{teamKey}/{projectKey}/plan/new` 以整页提供新建测试计划表单，并在 `/{teamKey}/{projectKey}/plan/{planId}/edit` 以整页提供编辑表单。系统 MUST NOT 再以覆盖计划列表的对话框作为列表「新建」「修改」或工作台快捷创建的主展示方式。

#### Scenario: 从列表新建进入整页

- **WHEN** 用户具备计划新增权限且在计划列表触发「新建」
- **THEN** 路由导航到当前项目的 `plan/new` 整页，且页面展示计划元数据表单与选用例区

#### Scenario: 从列表修改进入整页

- **WHEN** 用户具备计划修改权限且在计划列表对某计划触发「修改」
- **THEN** 路由导航到该计划的 `plan/{planId}/edit` 整页，且表单回填该计划数据与已选用例

#### Scenario: 工作台快捷创建进入新建整页

- **WHEN** 用户从工作台快捷创建触发新建计划
- **THEN** 路由导航到当前项目的 `plan/new` 整页

### Requirement: 选用例区左侧交付物列表可拖分栏

在新建/编辑整页的选用例区，系统 MUST 在左侧展示交付物相关树（团队开启交付物模块时），MUST 允许用户通过中缝拖拽调整左右栏宽度，交互与样式 MUST 与测试用例列表页的左右分栏一致（可拖、可隐藏侧栏、宽度可记忆）。交付物仍用于筛选与批量勾选用例，MUST NOT 要求单独持久化「计划绑定的交付物列表」。

#### Scenario: 拖拽改变侧栏宽度

- **WHEN** 用户在选用例区拖动左右分栏中缝
- **THEN** 左侧交付物区域宽度随之变化，松手后宽度在后续同会话（或既有缓存策略）中可恢复

#### Scenario: 交付物模块关闭时

- **WHEN** 当前团队未开启交付物模块
- **THEN** 左侧交付物树按既有闸门逻辑不展示（或等价隐藏），选用例表仍可用

### Requirement: 保存成功与取消返回计划列表

系统 MUST 在保存新建或编辑成功后导航回当前项目的测试计划列表；取消或显式返回 MUST 同样回到该列表。返回后侧栏 MUST 仍高亮测试计划模块。

#### Scenario: 保存成功回列表

- **WHEN** 用户在新建或编辑整页提交成功
- **THEN** 导航到 `/{teamKey}/{projectKey}/plan`，且列表展示最新数据（含刚保存的计划）

#### Scenario: 取消回列表

- **WHEN** 用户在新建或编辑整页触发取消或返回
- **THEN** 导航到当前项目的计划列表页

### Requirement: 深链打开新建或编辑页

系统 MUST 支持通过 `plan/new` 与 `plan/{planId}/edit` URL 直接打开对应整页（在具备相应权限时）。

#### Scenario: 打开编辑页 URL

- **WHEN** 用户访问 `/{teamKey}/{projectKey}/plan/{planId}/edit` 且具备修改权限
- **THEN** 系统展示该计划的编辑整页内容
