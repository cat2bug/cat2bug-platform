## Context

缺陷表格列表行内通过 `DefectTools` 暴露指派 / 修复 / 驳回 / 通过 / 关闭 / 重开 / 删除，各动作有独立弹窗（`AssignDialog`、`RepairDialog` 等），接口均为单条 `POST /system/defect/{id}/...`。列表 `table.vue` 曾预留 `ids` / `checkedDefectList`，但无勾选列；用例/文档列表已有勾选 + 批量删除可参考。Excel 视图交互不同，本期不接入批量。

## Goals / Non-Goals

**Goals:**

- 表格模式工具条「新建缺陷」前提供「批量操作」下拉；勾选 ≥1 即可用。
- 菜单可用性 = 状态集合规则 ∩ 与 `DefectTools` 一致的严格单条资格（状态、处理人/创建人、权限、未删除）。
- 需填写的动作用列表弹窗：逐行 + 顶部「应用到全部」；字段与对应单条弹窗一致。
- 删除仅确认框；提交串行现有 API，汇总成功/失败。

**Non-Goals:**

- Excel 模式批量（按钮隐藏）。
- 新增后端批量流转 API / 事务回滚。
- 跨页勾选、全库选中。
- 修改单条弹窗字段（例如重开不加处理人；与现网一致）。
- MCP 批量工具、通知策略改造。

## Decisions

### D1：前端编排 vs 后端批量 API

- **选择**：前端串行调用现有单条接口。
- **理由**：权限与状态校验已在服务端单条路径上完整；本期避免双份校验与部分成功语义设计。
- **备选**：`/batch-assign` 等 —— 体验与限流更好，工作量大，留待量上来后再做。

### D2：可见性逻辑复用

- **选择**：抽出与 `DefectTools` 相同的「单条动作是否可用」纯函数（或共享模块），批量菜单对选中集做 `every`。
- **理由**：严格策略要求与行内按钮一致，避免菜单亮但提交大面积失败。
- **备选**：菜单只按状态过滤、提交时再拦 —— 已否决（用户要求严格）。

### D3：同状态 vs 混合状态菜单

| 选中状态集合 | 候选动作 |
|---|---|
| 单一状态 | 该状态下 `DefectTools` 可能出现的动作 ∩ 严格 |
| 多个状态 | 仅指派、关闭、删除 ∩ 严格 |

同状态时额外可能出现：处理中/已驳回 → 修复；待审核 → 驳回/通过；已关闭 → 重开。

### D4：批量弹窗字段严格复刻单条

| 动作 | 人员 | 描述 |
|---|---|---|
| 指派 | 处理人必填 | 可选 |
| 修复 | 审核人必填 | 可选（默认审核人逻辑对齐 `RepairDialog`：可按条预填日志创建人，或顶部统一后再逐行改） |
| 驳回 | 无 | 必填 |
| 通过 | 无 | 可选 |
| 关闭 | 无 | 必填 |
| 重开 | 无（复刻现单条） | 必填 |
| 删除 | — | 确认框，无列表弹窗 |

顶部提供「应用到全部」写入每一行后仍可单行修改。

### D5：UI 挂载点

- 勾选列：`list/table.vue` 的 `Cat2BugTable`（`type="selection"` 或等价 prepend），`selection-change` 上抛到 `index.vue`（或由 table 暴露 `getSelection()`）。
- 批量下拉：`index.vue` 的 `#right-tools`，「新建缺陷」之前；`defectContentComponent === 'DefectExcel'` 时 `v-if` 隐藏。
- 批量弹窗：新建组件（如 `DefectBatchActionDialog`），按 `action` 切换列；删除用现有 `$modal.confirm`。

### D6：提交与反馈

- 串行 `await` 每条；一条失败不中断其余（与「前端无事务」一致）。
- 结束后 toast：成功 n / 失败 m；失败可列出编号与原因（简短）。
- 成功后刷新当前列表并清空勾选。

## Risks / Trade-offs

- **[Risk] 勾选较多时串行耗时长、通知风暴** → 按钮 loading；本期不限条数硬顶，若体验差再加上限或改批量 API。
- **[Risk] 可见性与 `DefectTools` 漂移** → 共享判定函数，改单条规则时同改。
- **[Risk] 重开单条不传处理人，后端 `handleBy` 可能为空** → 批量严格复刻，不在本期修复；若线上有问题另开变更。
- **[Risk] 列表行数据缺 `createById` / `handleBy` 导致误判** → 确认 list API 已返回与行内工具相同字段；缺则补字段或打开前拉详情（优先用列表字段）。

## Migration Plan

- 纯前端能力，无数据迁移。
- 回滚：隐藏批量按钮与勾选列即可，不影响单条流转。

## Open Questions

- 无（探索阶段已拍板：严格、≥1、Excel 隐藏、混合仅三动作、字段复刻单条、含修复/重开）。
