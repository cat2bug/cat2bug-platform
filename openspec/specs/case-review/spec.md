# case-review Specification

## Purpose

勾选用例发起可选评审，完成时生成可编辑 Markdown 纪要；评审不阻止用例进入测试计划。

## Requirements

### Requirement: 勾选用例发起一次评审

拥有用例评审权限的成员 SHALL 能够对当前项目中勾选的一批用例打开发起评审弹框。打开弹框 MUST NOT 改写用例的评审章。勾选里已处于评审中的用例 SHALL 被排除并说明编号，其余用例照常进入弹框；不得因其中有评审中的用例而整批失败。全部都在评审中时 SHALL 提示并且不产生评审。点「完成评审」时才写入数据库：生成已完成评审和 Markdown 纪要，并把纳入本次的每条用例的章更新为该条结论。没有评审权限的成员 MUST NOT 发起或完成评审。

#### Scenario: 打开发起评审

- **WHEN** 项目测试勾选本项目的两条未在评审中的用例并点击发起评审
- **THEN** 弹框立刻出现这两条用例，它们的评审章保持原样

#### Scenario: 勾选里夹着评审中的用例

- **WHEN** 用户勾选的用例里既有评审中的，也有未评审的，并点击发起评审
- **THEN** 弹框只包含未在评审中的用例，并说明被跳过的编号，不报整批失败

#### Scenario: 完成才写库

- **WHEN** 用户在弹框里为每条用例选择通过或需修改并点击完成评审
- **THEN** 产生一次已完成的评审和纪要，这些用例的章变为对应结论；在点击完成之前数据库不变

#### Scenario: 无评审权限

- **WHEN** 只有用例查看权限、没有评审权限的成员尝试发起评审
- **THEN** 操作被拒绝

### Requirement: 完成评审生成可编辑的 Markdown 纪要

完成评审时，每条被评用例 MUST 已有结论「通过」或「需修改」。系统 SHALL 用模版生成 Markdown 纪要并保存。项目未自定义模版时 MUST 使用内置模版。完成后 SHALL 把每条用例的章更新为该条结论。完成后 SHALL 允许修改纪要正文，且修改正文 MUST NOT 改变用例上的章或各条结论。

#### Scenario: 结论未齐不能完成

- **WHEN** 弹框里仍有一条用例没有「通过」或「需修改」的结论，用户点击完成评审
- **THEN** 不写入数据库，用例的评审章保持原样

#### Scenario: 完成后章与纪要一致

- **WHEN** 两条用例分别被标为通过和需修改，用户完成评审
- **THEN** 评审变为已完成，纪要正文包含这两条用例的编号、标题、结论和意见，两条用例的章分别为「通过」和「需修改」

#### Scenario: 使用项目自定义模版

- **WHEN** 项目管理员已保存一段自定义 Markdown 模版，用户完成一次评审
- **THEN** 纪要按该模版生成，而不是内置模版

#### Scenario: 改纪要不回写章

- **WHEN** 用户在已完成的评审里只修改纪要正文
- **THEN** 正文更新，用例的评审章与各条结论保持完成时的值

### Requirement: 评审不阻止用例进入测试计划

测试计划的新建与编辑在选择用例时 SHALL 提供类型与评审两个筛选项。评审筛选项 MUST 包含全部、未评审、评审中、通过、需修改，默认全部。筛选 MUST NOT 阻止把未评审或需修改的用例加入计划。

#### Scenario: 默认看到未评审用例

- **WHEN** 用户打开新建测试计划且不改筛选
- **THEN** 用例列表包含未评审的用例，并且可以勾选进计划

#### Scenario: 按通过筛选仍可改回全部

- **WHEN** 用户把评审筛成「通过」，然后再改回「全部」
- **THEN** 先只显示章为通过的用例，改回后未评审用例重新出现并可勾选

#### Scenario: 保存计划不检查评审章

- **WHEN** 用户把一条未评审用例加入计划并保存
- **THEN** 计划保存成功，该用例成为计划子项

### Requirement: 对外版本说明包含本能力

根目录 `README.md` 的「内置功能」与「最新版本更新说明」，以及首页更新日志中的 v1.1.0 条目，SHALL 写明：项目可配置用例类型，可对勾选的用例做可选评审并生成 Markdown 纪要，测试计划里评审只作为筛选项。本变更 MUST NOT 提升产品版本号。

#### Scenario: 说明出现在两处

- **WHEN** 读者查看 `README.md` 的最新版本更新说明和首页更新日志的 v1.1.0 条目
- **THEN** 两处都能看到用例类型、可选评审纪要，以及计划中评审为筛选项的说明，版本号仍为 1.1.0
