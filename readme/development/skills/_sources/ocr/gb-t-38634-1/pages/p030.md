46.4 基于数学方法的测试

当可以充分详细地描述测试项输入或输出范围时,基于数学方法的测试实践可用于计划设计、选
择数据和设置输和人条件。数学方法实践使用数学分支来推动。这些实践有助于减少测试用例选择和优
先级排序中人为困素的影响。

基于数学方法的实践用到了多种技术,特别是以下测试设计技术(在 GB/T 38634.4 中描述) :

一一组全测试，

一一随机测试用例选择 。

此外,统计建模可用于确定测试覆盖率(未在 GB/T 38634.4 中提及) ,例如:

一一分层抽样;

一一模糊测试;

— MH:

一一专家判断抽样。

基于数学方法的测试实践,也可使用基于数学的工具和技术客观地对测试用例进行采样。

使用数学方法的实践通常会产生大量的输入,因此通常需要使用自动化工具来实现。

GB/T 38634.4 描述基于经验的测试设计技术中的错误猪测。其他基于经验的测试方法包括(但不
限于)探索性测试.软件攻击和特别测试。探索性测试和软件攻击不作为 GB/T 38634.4 所包含的测试
设计技术。因为这两种技术应用了多种测试设计技术。

探索性测试压缩了 GB/T 38634.2 中*测试设计和实现"和*测试执行"过程描述的活动,以便动态
执行这些活动完成测试目标。当使用探索性测试时 ,测试用例通常不会提前设计和记录,测试人员使用
直觉.好奇心和先前测试的结果来决定接下来测试的内容和方法。

探索性测试 .错误猪测和特殊测试是不依赖于大量文档(例如测试规程)来执行测试的测试实践。
