详细的测试子过程示例
D.1 概述
本附录列举了测试子过程的示例。这些示例以字母表的顺序排列。该列表只显示了一些示例;在
特定的测试项目中可能需要许多其他的特定子过程。
示例如下:
一一验收测试;
一一详细设计测试，
一一集成测试:
一一性能测试;
一一回归测试
一一复测;
一一故事测试;
一一系统测试
一一组件测试。
需要注意,回归测试和复测已经被包含在特定的测试子过程中。这些可以适当地包括在任何其他
测试子过程中。
每个示例的测试子过程的描述包括:
一一测试子过程的目标;
一一计划的测试子过程内容,要执行的静态和动态测试过程。
对于计划用于测试子过程的每个静态或动态测试过程 ,撒述包括;
一一测试目标;
一一测试项:;
一一测试依据;
一一适用的测试过程;
一一建议的测试设计技术(如适用) 。
请注意,示例只供人参考。在实际情况下 ,应根据产品的风险情况进行选择 。
