8.3.2 目的
测试环境构建和维护过程的目的是建立和维护所需的测试环境,并将其状态传达给所有利益相
关方。
8.3.3 结果
测试环境构建和维护过程成功实施的结果包括:
a) 测试环境处于可测试的就绪状态，
b) 将测试环境的状态传达给所有利益相关方;
c) 维护测试环境。
