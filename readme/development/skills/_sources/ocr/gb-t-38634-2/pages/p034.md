8.4.2 目的
测试执行过程的目的是在准备好的测试环境中执行测试设计和实现过程中创建的测试规程,并记
录结果。
8.4.3 BR
测试执行过程成功实施的结果包括:
a) 执行测试规程
b) 记录实测结果:
c) 比较实测和预期结果;
d) 确定测试结果 。
