B.1 概述
ISO/TEC/TEEE 12207 提供了生存周期过程的通用框架,其中包括一些与软件测试相关的活动和
任务。本附录从高层次给出了本部分如何映射到 ISO/TEC/TEEE 12207 的测试相关过程。
下面的高层次映射给出了 ISOVIECVIEEE 12207 的用户如何使用本部分。对于使用本部分而不使
用 ISO/TEC/TEEE 12207 的用户 ,本附录是可选的。
ISO/TEC/TEEE 12207 中使用的测试相关的术语映射在 GB/T 38634.1 概念和定义中提供。
