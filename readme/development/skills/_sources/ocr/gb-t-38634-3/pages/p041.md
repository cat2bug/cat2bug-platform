7.8.4.2 ”唯一标识符
在测试环境需求文档中使用的唯一标识符。

描述所需测试环境项的满足情况。
示例:请足声明可以包括对实际测试环境如何偏离需求的描述,例如在版本或配置方面。

可用,它们可能会对测试产生影响。
