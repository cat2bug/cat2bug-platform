织级测试策覆。
范围:组织级油试策咯提供了企业整体的测试方法。企业开发并实现了一系列适用于所有项目的准则,目标是在系
统与软件生存周期的每个环节提供测试。该目标是通过让测试小组尽早参与到软件生存周期过程中,参与开发人员团
WA ,处理甘至在草稿状态下的用户故事来实现。这些相关的做法为建立相关测试计划,并且确立基本范围提供了基础。
除了开发测试计划,组织还开展敏搂测试活动,例如利益相关方参与测试设计、准备注试自动化,同行评审.各种测试设
计技术(项目适用)以及轻量级的缺陷跟踪和报告。
引用文档:做捷宜言。
通用的风险管理:所有风险管理必须遵特公司 RM56 方针中定义的企业风险管理规定,该规定明确了一般风险标
记。 任何偏差和放弃都必须得到高级管理人员的批准。
独立程度:企业测试组织由测试负责人进行领导,测试负责人与开发负责人没有直接的关系。测试组织在技术、管
理和财务上都独立于敏捷企业 A 的开发组织,而在某个项目中,指定的测试人员可以直接参与自发组织的团队,其中包
括开发。
