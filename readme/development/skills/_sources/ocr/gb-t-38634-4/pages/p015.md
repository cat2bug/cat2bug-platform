5.2.5 ”组合测试设计技术
5.2.5.1 概述
组合测试设计技术用于系统地导出有效且可控的测试用例子集,其在测试期间覆盖了导出的测试
条件和测试厢盖项。组台是根据测试项参数和参数可取的值来定义的。当多参数(每个参数都有大量
离散值)必须相互作用的情况下,这种技术可以显著减少所需的测试用例数量,而不会影响功能覆盖率。
