5.2.9 ”场景测试
5.2.9.1 导出测试条件 (TD2)
场景测试使用测试项与其他系统之间的交互序列模型(在此周境中,用户通常被认为是其他系统)。
以测试所涉及的测试项使用流程测试条件应是一个交瑟序列(即一个场景)或所有交互序列(即所有
场景) 。
场景测试应该但括以下场景:
-一一主"场景是测试项的预期典型动作序列,或无典型动作序列时所采取的一个任意选择:和
一一"备选"场景表示测试项可选择的(非主)场景。
注1; 备选的场鞭包括非正常的使用,舱端或者压力条件和更常。
注 2; 场景测试通常在功能调试中用于产生*端到端测试",比如系统测试或者验收测试。
场景测试的一种常见形式称为用例测试,其采用了测试项的用例模型来描述测试项如何与一个或
多个参与者交互,以测试相关测试项的交互序列(即场景) 。
注3: 在用前测试中,用例模型用于描述参与者如何触发测试项的各种动作。 参与者可以是用户或其他系统。
注4: 事务流测试也是一种场景测试。
