6.2.2，分类树方法覆盖率
分类树方法的覆盖率根据组合分类导出测试禾盖项的方式不同 ,分为以下定义类别:
对于最小化组合覆盖率,应使用以下定义:
一一上获盖率是最小组全分类树方法的覆盖率;
一一N 是执行的测试用位蓝盖的类数量;
一一工是类的总数量，
对于最大化组合覆益率,应使用以下定义:
一一先盖率是最大组合分类树方法的著羔率;
一一N 是执行的测试用例柳盖的类组合数量;
一一了工是类组合的总数报。
