# GB/T 38634.4 — PDF page 35

GB/T 38634.4一2020
易用性测试使用的测试项烧型指定了其易用性要求,包括测试项应符合的任意易用性设计标准。易用
性需求指定了测试项的易用性目标，易用性目标应是基于测试项的目标(原因是调试项可以给组织或
者个人带来的不同之处,用以帮助实现易用性相关的目标并完成相关的任务)*和测试项使用的周境(谁
使用涡试项.将使用什么样的环境以及用户特性和用户任务)。易用性县标定义为特定用户在一个或多
个指定的周境中达到指定的有效性 ,效率和满意度目标。
注: ISO/IEC 9241 系列标准定义了人机交五要求的标准。
