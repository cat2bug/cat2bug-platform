B.2.4.1 介绍
语法测试的目的是根据语法覆盖率的要求导出测试用例集,这些测试用例能够覆盖测试项所有和输
大的语法。语法测试是基于对测试项的测试基础的分析,通过对输人的语法措述来对其行为建模。通
过一个样例来说明这个技术。只有当定义的语法和要求的语法一致时,语法测试寺有效。
