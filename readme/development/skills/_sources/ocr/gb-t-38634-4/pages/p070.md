B.2.6 判定表测试
B.2.6.1 介绍

判定表测试的目的是根据所选择的条件和动作覆盖级别导出测试用例集,以覆盖输入和和输出(即一
系列条件和动作)的丈辑关系:输入和输出与判定规则相关。
B.2.6.2 ”规格说明

以支票各记功能为例.输入是借记人金灾 ,账户类型和当前余额,输出是新的余额和操作代码: 账户
类型是时政(“p”)类型或柜台(ec”)类型。操作代码是DEL”D7”S& EL"或<L”分别对应"处理借记江
发送信件交只处理借记多冻结账户和发送信件"和“只发送信件"”。该功能的测试依据如下，

如果账户中有是够的金额或者新的余额在授权透支的范围内,则处理借记。如果新的余额超过了
授权透支的范围,则不处理借记,如果是一个邮政账户则进行冻结。邮政账户的所有交易都会发送信
件,非地政账户如果有是够的资金也会发送信件(即账户将不再是信贷)。
