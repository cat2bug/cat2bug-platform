系。该技术利用了一种约定来表示测试的因果图,该图显示了原因和结果之间的关系以及它们之间的
显式约束。和判定表测试不同 ,判定表的约束没有旺式地声明。因此,该技术只是对模型覆盖测试项的
测试依据的一种扩展。
