B.2.8.6.1 选项
现在可以导出检验每个可能的转移的测试用例。可以从状态转移图中获得输大.用于检验每个测
试用例中覆盖的转移,同时可以从状态转移图的预期结果和转移的结束状态获得预期结果。导出的测
试用例中,每个测试用例可以覆盖到转移,其中居是可能转移的最大数量: 例如,根据单步转移或
者 2 步转移覆盖可以导出测试用例(实际上同时导出单步转移和 2 步转移测试用例是没有必要的,这将
