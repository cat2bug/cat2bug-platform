C.2.3.1 介绍

分支条件测试,分支条件组合测试和修正条件判定测试是密切相关的,覆盖测量也是相关联的。三
种测试设计技术的目的是根据选择的覆盖率,导出测试用例集荐蕾测试项的判定条件。 下面用一个例
子说明测试用例设计和测试覆狂测量方法。

算。例如,布尔条件 A 可以是一个表达式 XS 立。为了更加清晰地说明,下面的例子都把A.B和C
