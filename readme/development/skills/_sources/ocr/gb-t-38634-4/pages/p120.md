E.1 可交换的测试设计技术的应用指南和示例
虽然本部分将技术分为基于结构.基于规格说明或基于经验的;实际上一些技术可以交换使用
《见 5.1》。下面的例子说明了分支测试(通常是指基于结构的技术)如何应用于基于规格说明的测试，
证明了技术可以交换使用。
