# Cat2Bug 与 QMS 证据映射

用途：Agent 编写 QMS 记录模版或向审核方说明证据时，对照下表。**QMS 记录正文优先人工填写**；Cat2Bug 侧以 **系统内可查数据 + 导出/截图/报告附件** 方式引用，不虚构 DSL 变量。

## 能力映射表

| QMS 需求 / 典型证据 | 证据要点 | Cat2Bug 功能与用法 | 局限 |
|---------------------|----------|-------------------|------|
| 项目与范围界定（4、8） | 交付边界、版本、模块划分 | **项目**、**模块**、项目简介与图标；测试计划关联模块 | 不替代合同/范围批准记录 |
| 质量/测试策划（6、8） | 计划、资源、进度、风险 | **测试计划**（名称、版本、项数）；计划与用例/模块关联 | 风险登记、机遇分析需在 QMS 记录或计划人工章节填写 |
| 运行控制 — 测试设计与执行（8） | 用例、执行结果、追溯 | **用例库**、计划项、执行状态；缺陷与用例/计划关联 | 非全生命周期 ALM；设计输入追溯靠人工引用需求编号 |
| 不合格与事件（8、10） | 缺陷描述、严重度、状态、处理 | **缺陷/事件**、状态流转、处理人、历史 | 非完整 CAPA 表单；纠正措施根因、有效性验证用 **records/** 模版 + 外部流程 |
| 监视与测量（9） | 测试进展、度量、趋势 | **测试状态/完成类报告模版**（`29119-3/`）+ 缺陷统计表导出 | 度量定义与目标值在 QMS 目标/KPI 记录中维护 |
| 成文信息 — 测试交付物（7、8） | 受控的报告与说明 | **报告模版**、项目内生成的报告实例；模版版本由组织在 Cat2Bug 外受控亦可 | 体系级「文件分发清单」不在产品内 |
| 沟通与评审痕迹（7、9） | 评审意见、批准 | **评论**、报告 **批注/注解**（若项目启用） | 不替代 signed 管评纪要、书面批准栏 |
| 职责与权限（5、7） | 谁可改缺陷、谁可管项目 | **成员**、**角色/权限**、项目访问控制 | 不记录 HR 岗位说明书 |
| 外来文件与标准（7） | 引用 GB/T、29119 等 | 报告模版文末「参考文档」；skills 索引 | 标准正版持有证明在组织文控 |
| 内审（9） | 审核计划、检查单、不符合 | 可导出缺陷/权限/日志类 **抽样清单** 作客观样本 | **无内审模块**；检查表用 `records/` |
| 管理评审（9） | 输入输出、决议 | 可附件：周期内 **完成报告**、缺陷趋势导出 | **无管评模块**；纪要用 `records/` |
| 纠正措施（10） | 原因、措施、验证 | 缺陷处理记录作 **实施证据** 之一 | 8D/CAPA 闭环用外部或 `records/` |
| 能力意识培训（7） | 培训记录、授权 | — | **无培训 LMS**；签到与考核在外部 |
| 设计开发（8.3） | 评审、验证、确认 | 测试报告、用例覆盖说明可作 **V&V 证据片段** | 需求/设计文档通常在外部工具 |
| 外部提供过程（8.4） | 供应商评价、外包测试 | 项目成员与权限可反映 **协作方** 访问范围 | 供应商名录与评价在 QMS 记录 |
| 数据分析与改进（9、10） | 趋势、改进项 | 缺陷按状态/模块/时间导出；完成报告摘要 | 改进立项在 QMS 或项目管理工具 |

## 推荐使用方式（Agent 写模版）

1. **QMS 记录**（内审、管评、纠正措施）：章节用 **（人工填写）** / **【待填写】**；「客观证据附件」小节列出可从 Cat2Bug 导出的 **类型**（如：某项目测试完成报告 PDF、缺陷清单 CSV、某报告批注截图），不写未文档化的 `${api.*}`。
2. **测试报告模版**（29119-3）：在 DSL 已文档化处使用 `${api.project.*}`、`${api.plan.*}` 等；文末可加一句「本报告若作为 QMS 记录附件，须与 **记录编号、批准栏** 一并归档」。
3. **缺口**：下表能力 ** intentionally 不假装已有** — 模版中留空栏并指向组织程序。

## 明确缺口（须外部流程或 records 模版）

| 缺口 | 建议 |
|------|------|
| 培训与能力管理 | HR 或 LMS；QMS 培训记录模版 |
| 完整 CAPA / 8D | `records/` 纠正措施单 + 缺陷号交叉引用 |
| 管理评审 | `records/` 管理评审纪要 + 输入材料清单 |
| 内部审核 | `records/` 内审计划/检查表/不符合报告 |
| 文件化信息全局受控 | 文控系统或 Git + 发行程序；Cat2Bug 模版仅为其中一类交付物 |
| 供应商管理 | `records/` 供应商评价与再评价 |
| 计量与校准 | 计量台账在外部 |
