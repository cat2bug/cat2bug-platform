## 程序步骤

### 设计和开发策划

（人工填写）里程碑、职责、接口、评审/验证/确认安排、资源与 Cat2Bug 项目/迭代映射（如适用）。

### 设计和开发输入

（人工填写）功能/性能/法规/接口/验收准则等输入清单及评审；输入变更控制。

### 设计和开发控制

#### 评审

（人工填写）评审点、参与人、问题跟踪与关闭标准。

#### 验证

（人工填写）验证方法与证据（含测试用例执行、单元/集成/系统级验证）；引用《测试与验证控制程序》。

#### 确认

（人工填写）顾客或模拟使用场景确认、验收准则满足证据。

### 设计和开发输出

（人工填写）输出清单（规格、设计说明、代码基线、用户文档等）；输出与输入对照；可测试性与追溯性要求。

### 设计和开发更改

（人工填写）变更申请、影响分析、再验证/再确认、批准与通知；与缺陷关联变更的规则。

### 与测试、缺陷闭环的接口

（人工填写）例如：

- 设计输出中的验收准则同步至测试说明/用例（Cat2Bug 或 `../29119-3/test-specification.md` 模版）；
- 测试缺陷作为设计/实现不符合的来源，按《不符合与纠正措施程序》处置；
- 准出前开放缺陷等级与放行规则（人工填写准则）。
