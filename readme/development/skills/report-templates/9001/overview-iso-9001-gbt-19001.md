# ISO 9001:2015 与 GB/T 19001-2016 概要

## 标准关系

| 标准 | 说明 |
|------|------|
| ISO 9001:2015 | 质量管理体系 — 要求（国际版） |
| GB/T 19001-2016 | 等同采用 ISO 9001:2015 的国家推荐性标准 |

**条款编号 4–10 及子条款结构一致**；认证审核通常按同一逻辑检查。逐字「应」要求以组织持有的 **正版标准文本** 为准。

## 条款 4–10 意图摘要（中文标题）

下列为各章 **目的级** 说明（1–2 句），便于 Agent 对齐模版章节，**非标准原文**。

### 4 组织环境

理解组织内外部议题、相关方需求与期望，确定质量管理体系 **范围**，并将过程及其相互作用纳入体系进行管理。

### 5 领导

最高管理者对体系 **承担领导责任**：质量方针、角色职责与权限、以及「以顾客为关注焦点」在组织内的落实。

### 6 策划

针对质量目标与变更进行策划，识别 **风险与机遇**，并策划如何实现目标及应对风险机遇的措施。

### 7 支持

提供运行体系所需的 **资源**（人员、基础设施、环境、监视测量资源、知识等），确保人员能力、意识、沟通，以及 **成文信息** 的创建、更新与控制。

### 8 运行

策划并控制产品与服务 **实现过程**（含运行策划、要求确定、设计与开发、外部提供过程控制、生产与服务提供、放行、不合格输出控制等）。软件组织常在此引用测试、配置、发布等具体程序。

### 9 绩效评价

**监视、测量、分析与评价** 质量绩效；按计划实施 **内部审核**；按策划进行 **管理评审**，以评价体系的适宜性、充分性和有效性。

### 10 改进

对 **不符合** 作出反应，采取纠正措施，并持续改进质量管理体系的 **适宜性、充分性和有效性**。

## 成文信息（贯穿各章）

标准多处要求 **保持** 或 **保留** 成文信息：前者多指受控的程序与规定，后者多指 **记录** 以提供证据。写 QMS 模版时区分「文件版本管理」与「记录不可篡改/可追溯」两类栏位。

## 认证周期（高层概要）

以下为行业常见做法的 **概念层** 描述，具体以所选 **认证机构** 与 **认可规则** 为准，本文件不复制任何认证机构或书籍的流程表。

| 阶段 | 典型目的 |
|------|----------|
| 初次认证 — 第一阶段 | 审核 **文件与策划**：体系范围、关键过程、成文信息是否满足标准意图，为现场审核做准备 |
| 初次认证 — 第二阶段 | **现场（或等效）审核**：在范围内抽样验证运行与记录，确认实施有效性 |
| 监督审核 | 证书有效期内 **周期性** 短审核，确认体系持续符合并有效运行 |
| 再认证 | 证书周期届满前的 **全面或简化** 再审核，以延续认证 |

软件测试与缺陷管理活动通常作为 **8 运行** 与 **9 绩效评价** 的证据链一环；Cat2Bug 可支撑部分运行与记录导出，见 [cat2bug-qms-mapping.md](./cat2bug-qms-mapping.md)。

## 与测试标准的关系

GB/T 38634 / ISO 29119 系列描述 **测试过程与测试文档**；GB/T 19001 描述 **整个 QMS**。二者可并存：测试文档满足客户与测试标准，QMS 记录证明评审、批准、内审与改进闭环。边界见 [vs-29119-3.md](./vs-29119-3.md)。
