## Part 1 — 概念（摘要）

- 统一「测试项、测试条件、覆盖、级别、类型、回归」等说法，避免模版章节混用未定义词。

- **源**：GB OCR 计划路径 `_sources/ocr/gb-t-38634-1/`（**待落盘**）。写 skill 定稿前勿声称已核对 GB 原文。

## Part 2 — 过程（摘要）

三类过程簇（与 Part 3 文档分章对齐）：

| 过程簇 | 典型输出文档（Part 3） |
|--------|------------------------|
| 组织级测试过程 | 测试方针、组织级测试实践 |
| 测试管理过程 | 测试计划、测试状态报告、测试完成报告 |
| 动态测试过程 | 模型/用例/规程说明、数据与环境需求与就绪、实际结果、执行日志、事件报告 |

- 裁剪（tailored）：可不产生某类文档，但须记录子集并说明未满足 shall 的理由（见 Part 3 Clause 4）。
- **源**：`_sources/ocr/gb-t-38634-2/`。过程活动级 shall 以 GB/ISO Part 2 为准；本仓库当前以 Part 3 切片支撑**文档边界**。
