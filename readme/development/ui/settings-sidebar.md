# 设置页左侧分组导航 — 设计规范

参考实现：`SettingsLayout.vue`  
Cursor 规则：`.cursor/rules/ui-settings-sidebar.mdc`

## 问题与目标

组名（如「仓库设置」）与功能（如「基本信息」）若同色、同字号、齐左对齐，会看成一列菜单，**根本分不清层级**。

目标：组名是**分类标签**，功能是**缩进后的可点入口**。

## 规格

```
仓库设置                 ← 12px / secondary / 不可点
  基本信息               ← 14px / primary / 可点（选中淡底，无竖线）
  删除仓库
────────────────
访问控制
  仓库成员管理
```

| 元素 | 规格 |
|------|------|
| 侧栏宽 | 280px |
| 组名 | 12px、secondary、字重 600、无指针 |
| 功能列表 | 相对组名向右缩进；**不要**左侧竖线 |
| 功能项 | 14px、primary；hover/active 淡底圆角 6px |

## 反例

- 组名做成和功能一样粗的「菜单项」
- 组与功能齐左、无缩进、无分隔
- 选中只变蓝字、无背景
